    2.7. Expressions regulars¶

    1. Què són i com s'usen¶

    En PHP, les expressions regulars (PCRE) s'utilitzen amb les funcions preg_*.

    Sempre s'indica un delimitador al voltant del patró (habitualment /).

    Estructura general:

    /<patrón>/<modificadores>

    Exemple mínim:

    <?php
$patron = '/\d+/';           // uno o más dígitos
$texto  = 'Tengo 12 perros';

if (preg_match($patron, $texto, $m)) {
    echo "Hay un número: {$m[0]}";   // "12"
}
?>

    2. Funcions preg_* principals¶

    Funció Què fa Retorna
    preg_match($patrón, $texto, &$coinc) Retorna només la primera coincidència 1 si hi ha match, 0 si no
    preg_match_all($patrón, $texto, &$coinc) Retorna totes les coincidències en un array
    preg_replace($patrón, $reemplazo, $texto, $lim=-1, &$count=null) Reemplaça per patró.
    -1 → sense límit de reemplaçaments (si poses 1, només canvia la primera coincidència).    		 String
    preg_replace_callback($patrón, $callback, $texto) Permet aplicar una funció de callback a cada coincidència del patró. D'esta manera pots transformar dinàmicament el valor trobat. String
    preg_split($patrón, $texto, $lim=-1) Dividix un string per patró.
    -1 significa que no hi ha límit de divisions.    		 Array
    preg_grep($patrón, $array) Filtra un array per regex Array
    preg_last_error() Útil després de preg_*.
    Retorna un codi numèric que indica l'últim error produït per una funció d'expressions regulars.
    PREG_NO_ERROR → 0,
    PREG_INTERNAL_ERROR → 1,
    PREG_BACKTRACK_LIMIT_ERROR → 2,
    PREG_RECURSION_LIMIT_ERROR → 3,
    PREG_BAD_UTF8_ERROR → 4,
    PREG_BAD_UTF8_OFFSET_ERROR → 5,
    PREG_JIT_STACKLIMIT_ERROR → 6    		 Constant numèrica.

    Exemples:

    <?php
$patron = '/\d+/';           // uno o más dígitos
$texto  = 'Tengo 12 perros';

if (preg_match($patron, $texto, $m)) {
    echo "Hay un número: {$m[0]}";   // "12"
}
?>

    <?php
$patron = '/\d+/';           // uno o más dígitos
$texto  = 'Tengo 12 perros, 4 gatos y 7 periquitos';

if (preg_match_all($patron, $texto, $coincidencias)) {
    echo "Números encontrados:<br>";
    foreach ($coincidencias[0] as $num) {
        echo $num . "<br>";
    }
}
?>

    <?php
$patron  = '/\d+/';             // uno o más dígitos
$reemplazo = '#';               // sustituir números por #
$texto   = 'Tengo 12 perros y 4 gatos';

$nuevoTexto = preg_replace($patron, $reemplazo, $texto, -1, $count);

echo "Texto original: $texto<br>";
echo "Texto modificado: $nuevoTexto<br>";
echo "Reemplazos realizados: $count";
?>

    <?php
$patron = '/\d+/';   // uno o más dígitos
$texto  = 'Tengo 12 perros y 4 gatos';

// Callback: recibe cada coincidencia y devuelve el nuevo valor
$nuevoTexto = preg_replace_callback($patron, function($coincidencia) {
    // $coincidencia es un array, el índice [0] es el valor encontrado
    $numero = (int)$coincidencia[0];
    return $numero * 2;   // multiplicamos por 2 cada número encontrado
}, $texto);

echo "Texto original: $texto<br>";
echo "Texto modificado: $nuevoTexto";
?>

    <?php
$patron = '/\d+/';   // dividir por uno o más dígitos
$texto  = 'Tengo 12 perros y 4 gatos';

// dividimos el texto por los números
$partes = preg_split($patron, $texto, -1);

echo "Texto original: $texto<br>";
echo "Partes obtenidas:<br>";
foreach ($partes as $p) {
    echo "- $p<br>";
}
?>

    <?php
$patron = '/^A/';   // elementos que empiezan por "A"
$array  = ["Ana", "Pedro", "Andrés", "Lucía", "Alba", "Juan"];

$resultado = preg_grep($patron, $array);

echo "Elementos originales:<br>";
print_r($array);

echo "<br><br>Coincidencias:<br>";
print_r($resultado);
?>

    <?php
$patron = '/[a-z/';   // patrón incorrecto (falta cerrar corchete)
$texto  = 'Hola Mundo';

preg_match($patron, $texto);

echo preg_last_error();
?>

    3. Delimitadors i escapament¶

    • Delimitador més comú: /.
    • Si el teu patró conté moltes barres /, usa'n d'altres: #patrón#, ~patrón~, ~https?://~.
    • Els delimitadors s'han de tancar i els modificadors van al final: /\d+/u.
    • Si el mateix delimitador apareix dins del patró, escapa'l o canvia de delimitador.

    4. Modificadors útils¶

    Mod Significat Efecte
    i Case-insensitive '/hola/i' aparella Hola
    m Multilínia ^/$ funcionen per línia
    s Dotall . també aparella salts de línia
    u Unicode (UTF-8) Recomanat per a accents/ñ
    U Ungreedy Quantificadors mandrosos per defecte
    x Extended Permet espais/comentaris en el patró
    A Àncora d'inici El patró ha de començar en l'índex 0
    D $ només al final real Evita casar abans del \n final
    J Duplicar noms de grups Casos avançats

    Exemple Unicode: '/^\p{L}+$/u' coincidix només amb lletres (inclou accents i ñ).

    5. Sintaxi del patró (xuleta)¶

    Classes i metacaràcters¶

    Expressió Significa
    . Qualsevol caràcter (excepte \n si no hi ha s)
    \d / \D Dígit / no dígit
    \w / \W “Word char” (lletra, dígit, _) / el contrari
    \s / \S Espai en blanc / no espai
    [abc] a o b o c
    [^abc] qualsevol excepte a, b, c
    [a-z] rang
    \p{L} lletra Unicode
    \p{N} número Unicode

    Àncores¶

    Expressió Significa
    ^ Inici de cadena (o línia amb m)
    $ Fi de cadena (o línia amb m)
    \b / \B Límit / no límit de paraula

    Quantificadors¶

    Expressió Significa Cobdiciós / Mandrós
    a? 0 o 1 ? / ??
    a* 0 o més * / *?
    a+ 1 o més + / +?
    a{n} exactament n —
    a{n,} almenys n , / ,?
    a{n,m} entre n i m } / }?

    Grups, backreferences, lookarounds¶

    Expressió Significa
    ( ... ) Grup capturador
    (?: ... ) Grup no capturador
    (?P<nombre> ... ) Grup amb nom
    \1, \2 Backreferences per índex
    (?= ... ) Lookahead positiu (afirmació cap avant)
    (?! ... ) Lookahead negatiu
    (?<= ... ) Lookbehind positiu
    (?<! ... ) Lookbehind negatiu

    6. Exemples pràctics¶

    preg_match (extraure una dada)¶

    <?php
$texto = 'Pedido #A-2025-0098 listo';
if (preg_match('/#([A-Z]-\d{4}-\d{4})/', $texto, $m)) {
    echo $m[1]; // A-2025-0098
}
?>

    preg_match_all (totes les coincidències)¶

    <?php
$html = '<a href="https://site.com">x</a> y <a href="http://ejemplo.es">y</a>';
preg_match_all('/href="([^"]+)"/', $html, $m);
print_r($m[1]); // ["https://site.com", "http://ejemplo.es"]
?>

    preg_replace (neteja normalitzada)¶

    <?php
$nombre = "  María   López  ";
$limpio = preg_replace('/\s+/', ' ', trim($nombre));
// "María López"
?>

    preg_replace_callback (transformació amb lògica)¶

    <?php
$texto = "IVA: 21%, Precio: 123.45€";
$salida = preg_replace_callback('/\d+(\.\d+)?/', function($m) {
    // formatear con coma decimal
    return number_format((float)$m[0], 2, ',', '.');
}, $texto);
// "IVA: 21,00%, Precio: 123,45€"
?>

    preg_split (CSV “simple”: comes amb espais)¶

    <?php
$csv = 'manzana, pera ,  uva';
$partes = preg_split('/\s*,\s*/', trim($csv));
// ["manzana","pera","uva"]
?>

    Grups amb nom i backreferences¶

    <?php
$fecha = '2025-09-18';
if (preg_match('/(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})/', $fecha, $m)) {
    echo "{$m['d']}/{$m['m']}/{$m['y']}"; // 18/09/2025
}
?>

    Assercions (lookahead) per a validar una contrasenya (simple)¶

    <?php
$pwd = 'Abcde1!';
$patron = '/^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{6,}$/';
echo preg_match($patron, $pwd) ? 'OK' : 'KO';
?>

    Espanyol/Unicode: paraules amb accents i ñ¶

    <?php
$texto = 'camión acción año café';
preg_match_all('/\b\p{L}+\b/u', $texto, $m);
print_r($m[0]); // reconoce bien tildes y ñ (¡usa 'u'!)
?>

    Reemplaçar només fora d'etiquetes <code> (avançat)¶

    Per a HTML real, millor un analitzador (DOMDocument). Exemple didàctic: 

    <?php
$txt = 'Esto es <code>hola</code> y hola fuera';
$pat = '~(<code>.*?</code>)|hola~s';
$out = preg_replace_callback($pat, function($m){
    if (!empty($m[1])) return $m[1]; // bloque code intacto
    return 'HOLA';
}, $txt);
// "Esto es <code>hola</code> y HOLA fuera"
?>

    7. Patrons típics de referència¶

    Cas Patró Nota
    Email (simple) /^[\w.+-]+@[\w.-]+\.\w{2,}$/i Bàsic; per a producció cal usar validació addicional
    URL http/https ~^https?://[^\s/$.?#].[^\s]*$~i Aproximat
    DNI (simple) /^\d{8}[A-Za-z]$/ La lletra es calcula a banda
    NIF/NIE (bàsic) /^[XYZ]?\d{7,8}[A-Za-z]$/ Comprovar la lletra per codi
    Data YYYY-MM-DD /^\d{4}-\d{2}-\d{2}$/ Valida el format, no el calendari
    Telèfon ES (flex) /^\+?34?\s?(\d[\s-]?){9}$/ Ajustar al format desitjat
    Només lletres Unicode /^\p{L}+$/u Inclou accents/ñ

    8. Consells i “gotchas”¶

    • Amb accents/ñ: usa el modificador u (/…/u) per al mode UTF-8.
    • En HTML real, millor un analitzador que regex pura (DOMDocument).
    • Evita patrons excessivament cobdiciosos (.*). Preferix ancorar (^...$) o usar ? mandrós.
    • Si alguna cosa falla, revisa els delimitadors i l'escapament.
    • Per a problemes estranys/de rendiment, inspecciona preg_last_error() i simplifica les alternances.

    9. Receptes ràpides¶

    A) Extraure el domini d'un email 

    <?php
$email = 'alguien@iesmre.es';
preg_match('/@([^@]+)$/', $email, $m);
echo $m[1]; // iesmre.es
?>

    B) Convertir ==> en la fletxa → excepte dins de cometes 

    <?php
$txt = 'a ==> b, "x ==> y"';
$pat = '/"[^"]*"(*SKIP)(*F)|==>/'; // PCRE verbs
$out = preg_replace($pat, '→', $txt);
// 'a → b, "x ==> y"'
?>

    C) Normalitzar espais i guions 

    <?php
$s = "Gestión   de   Contenidos--- WordPress";
$s = preg_replace('/\s+/', ' ', $s);
$s = preg_replace('/-{2,}/', '-', $s);
// "Gestión de Contenidos- WordPress"
?>

    D) Partir per línies buides (paràgrafs) 

    <?php
$bloques = preg_split("/\R{2,}/", $texto); // \R = cualquier salto
?>

    Aprendre expressions regulars

    Quines cadenes de text trobarien les regexp següents?

      a) hola
      b) h.?a
      c) h+b.
      d) [2-4]?[3-9ag]
      e) aju{2,8}m[-.]z
      f) (ad)+juju.[0-9]?-
      g) (ho|la)?[4-7zu]
      h) [([0-4][0-9]|5[0-2])[0-9]{3} . Codis postals d'Espanya
      i) ^.{3,32}#[0-9]{4}$ . Usuari de Discord
      j) (b25[0-5]|b2[0-4][0-9]|b[01]?[0-9][0-9]?)(.(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)){3} . Adreça ipv4. b és un delimitador de paraula «boundary».
