# <img src="../../img/php_azul.svg" width="40"> 2.3. Operadors

En PHP, els **operadors** són símbols que permeten realitzar operacions sobre variables i valors.

## 1. Tipus d'operadors en PHP

### 1.1. Operadors aritmètics
S'utilitzen per a realitzar operacions matemàtiques bàsiques:

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| **`+`** | Suma | $x + $y |
| **`-`** | Resta | $x - $y |
| **`*`** | Multiplicació | $x * $y |
| **`/`** | Divisió | $x / $y |
| **`%`** | Mòdul (residu) | `$x % $y |
| **`**`** | Potència | $x ** $y |


### 1.2. Operadors d'assignació
Servixen per a assignar valors a variables. El més usat és `=`, però n'hi ha de combinats:

| Operador | Equivalència | Exemple |
|----------|--------------|---------|
| **`=`** | Assigna un valor | $x = 10 |
| **`+=`** | `$x = $x + y` | $x += 5 |
| **`-=`** | `$x = $x - y` | $x -= 2 |
| **`*=`** | `$x = $x * y` | $x *= 3 |
| **`/=`** | `$x = $x / y` | $x /= 4 |
| **`%=`** | `$x = $x % y` | $x %= 2 |


### 1.3. Operadors de comparació
Permeten comparar valors, i retornen `true` o `false`.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| **`==`** | Igual a (valor) | $x == $y |
| **`===`** | Idèntic (valor i tipus) | $x === $y |
| **`!=`** o **`<>`** | Distint | $x != $y |
| **`!==`** | No idèntic | $x !== $` |
| **`>`** | Major que | $x > $y |
| **`<`** | Menor que | $x < $y |
| **`>=`** | Major o igual | $x >= $y |
| **`<=`** | Menor o igual | $x <= $y |
| **`<=>`** | Nau espacial (compara 3 valors possibles: -1, 0, 1) | $x <=> $y |

!!!examplephp "Diferència entre `==` i `===`"
    === "Exemple"

        ```php
        <?php

        $a = 5;
        $b = "5";

        var_dump($a == $b);
        var_dump($a === $b);

        ?>
        ```

    === "Resultat"

        Retorna:
        ```bash
        bool(true)
        bool(false)
        ```

### 1.4. Operadors d'increment/decrement
Permeten augmentar o disminuir valors de manera ràpida.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| **`++$x`** | Preincrement | Augmenta $x abans d'usar-lo |
| **`$x++`** | Postincrement | Usa $x i després l'augmenta |
| **`--$x`** | Predecrement | Disminuïx $x abans d'usar-lo |
| **`$x--`** | Postdecrement | Usa $x i després el disminuïx |

!!!examplephp "Diferència entre `++$x` i `$x++`"
    === "Exemple `++$x`"
        ```php
        <?php

            $x = 5;

            $y = ++$x;

            echo $x;   // retorna 6
            echo $y;   // retorna 6
        ```

    === "Exemple `$x++`"
        ```php
        <?php

            $x = 5;

            $y = $x++;

            echo $x;   // retorna 6
            echo $y;   // retorna 5
        ```

### 1.5. Operadors lògics
S'empren en expressions condicionals.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| **`and`** / **`&&`** | Vertader si les dues condicions són certes | cond1 && cond2 |
| **`or`** / `||` | Vertader si almenys una condició és certa | cond1 || cond2 |
| **`xor`** | Vertader si només una condició és certa | cond1 xor cond2 |
| **`!`** | Negació | `!cond1` |



### 1.6. Operadors de cadenes
Servixen per a manipular text.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| `.` | Concatenació | $txt1 . $txt2 |
| `.=` | Concatenació amb assignació | $txt1 .= $txt2 |



### 1.7. Operadors d'arrays
Permeten combinar i comparar arrays.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| `+` | Unió d'arrays | $x + $y |
| `==` | Igualtat d'elements (mateix parell clau/valor) | $x == $y |
| `===` | Igualtat estricta (mateix ordre i tipus) | $x === $` |
| `!=` / `<>` | Diferent | $x != $y |
| `!==` | No idèntic | $x !== $y |



### 1.8. Operadors de tipus
Permeten comprovar tipus o instàncies d'objectes.

| Operador | Descripció | Exemple |
|----------|-------------|---------|
| `instanceof` | Comprova si un objecte pertany a una classe | `$obj instanceof MiClase` |


### 1.9. Operadors condicionals

Els **operadors condicionals** permeten assignar un valor depenent d'una condició.

| Operador | Nom                 | Exemple                       | Resultat |
|----------|---------------------|-------------------------------|-----------|
| `?:`     | Ternari             | $x = expr1 ? expr2 : expr3  | Assigna a `$x` el valor d'`expr2` si `expr1` és `TRUE`; en cas contrari, li assigna `expr3`. |
| `??`     | Fusió nul·la        | $x = expr1 ?? expr2         | Assigna a `$x` el valor d'`expr1` si este existix i no és `NULL`. Si `expr1` no existix o és `NULL`, s'assigna `expr2`. *(Disponible des de PHP 7)* |

!!!examplephp "Exemple d'operador ternari"
    === "Codi"
        ```php
        <?php
            $hora = 14;
            $formato = ($hora > 12) ? 24 : 12;
            echo "El formato es de $formato horas"
        ?>
        ```
    === "Resultat"
        <div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova235.png" alt="prova 235" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.7: Exemple d'operador ternari i cadena formatada</figcaption></figure></div>

> **Operador Elvis**
> 
> Si volem comprovar si una variable té valor i, si no, donar-li un valor determinat, usarem l'operador **`?:`** (es coneix com l'**operador Elvis** - [**https://en.wikipedia.org/wiki/Elvis_operator**](https://en.wikipedia.org/wiki/Elvis_operator){:target="_blank"}) amb la sintaxi **`expresión ?: valorSiVacio`.**
>   
> === "Exemple op. elvis"
>     ```php
>     <?php
>     $nombre = "";
>     echo "Nombre: " . ($nombre ?: "desconocido") . PHP_EOL;
>     
>     // se envía a través de un formulario:
>     // $nombre = "";
>     // $nombre = $_GET['nombre'] ?: "desconocido";
>     ?>
>     ```
> === "Resultat"

## 2. Treballant amb formularis

Les dades s'envien via URL amb el format `var1=valor1&var2=valor2…`.

Per exemple: `ejemplo.php?nombre=Homer&apellido1=Simpson`

Es dividix en dos passos:

1. Generar un formulari amb `action='archivo.php' method='GET'`
2. En el fitxer `.php` llegir les dades amb `$_GET['nombreVar']`

Separarem sempre que puguem el codi HTML del codi PHP. Per exemple, el formulari es col·loca en `saluda.html` i les dades es recullen en `saluda.php`:

!!!examplephp "Exemple de formulari i pas de variables"
    === "saluda.html"
        ```html
        <form action="saluda.php" method="get">
            <p><label for="nombre">Nombre: </label>
            <input type="text" name="nombre" id="nombre"></p>
            <p><label for="apellido1">Primer apellido:</label>
            <input type="text" name="apellido1" id="apellido1"></p>
            <p><input type="submit" value="enviar"></p>
        </form>
        ```
    === "saluda.php"
        ```php
        <?php
            $nombre = $_GET["nombre"];
            $apellido1 = $_GET["apellido1"];
        
            echo "Hola $nombre $apellido1";
        ?>
        ```


Si es volguera fer tot en un únic fitxer (**cosa que no és recomanable**), es pot fer de la manera següent:

```php
<form action="" method="get">
      <p><label for="nombre">Nombre: </label>
      <input type="text" name="nombre" id="nombre"></p>
      <p><label for="apellido1">Primer apellido:</label>
      <input type="text" name="apellido1" id="apellido1"></p>
      <input type="submit" value="enviar">
</form>
<p>
      <?php
            if(!empty($_GET['nombre'])) {
                  $nombre = $_GET["nombre"];
                  $apellido1 = $_GET["apellido1"];

                  echo "Hola $nombre $apellido1";
            }
      ?>
</p>
```

El treball amb formularis s'estudiarà en profunditat en la unitat 4, i es veurà que, a més de `GET`, es poden enviar les dades amb `POST`.

## 3. Condicions

### 3.1. if

La condició simple es realitza mitjançant la instrucció **`if`**. Entre parèntesis es posa la condició que s'avalua a *true* o *false*. Si no es posen claus, en compte d'obrir un bloc, s'executarà només la instrucció següent.

> **Sempre claus**
> 
> És recomanable posar claus sempre, encara que en el moment de codificar només hi haja una única instrucció. D'esta manera, queda preparat per a afegir més contingut en el futur sense provocar *bugs*.

=== "Exemple if"
	

    ```php
    <?php
          $hora = 8; // La hora en formato de 24 horas
          if ($hora === 8) {
                echo "Suena el despertador.";
          }
          echo "<br>";
          if ($hora === 8)
                echo "Suena el despertador.";
    ?>
    ```

=== "Resultat"

=== "Exemple if-else"

          $hora = 17; // La hora en formato de 24 horas

                echo "Son las " . $hora . " de la mañana";

### 3.2. switch

La sentència **`switch`** també permet treballar amb condicions múltiples:

=== "Exemple switch"
    ```php
    <?php
        $hora = 12; // La hora en formato de 24 horas
        switch ($hora) {
            case 9:
                echo "Es la hora de desayunar.";
                break;
            case 14:
                echo "Es la hora de la comida.";
                break;
            case 21:
                echo "Es la hora de la cena.";
                break;
            default:
                echo "Ahora no toca comer";
        }
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova234.png" alt="prova 234" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.12: Exemple de sentència condicional switch</figcaption></figure></div>

> **No oblides el `break`**
> 
> Un error molt comú és oblidar la instrucció `break` després de cada cas. Si no el posem, executarà el cas següent automàticament.


### 3.3. match

La sentència **`match`** es va introduir en la versió 8.0 i és molt semblant a l'estructura de `switch`, però té algunes diferències importants:

- `match` retorna un valor.
- No requerix usar `break` al final de cada cas.
- Utilitza comparacions estrictes (`===`), la qual cosa significa que tant el tipus com el valor han de coincidir.

=== "Exemple match"
    ```php
    <?php

    $estado = 'ok';
    
    $resultado = match ($estado) {
        'ok' => 'Todo está bien.',
        'error' => 'Ha ocurrido un error.',
        'pendiente' => 'Todavía está pendiente.',
        default => 'Estado desconocido.', // opción por defecto, similar a "default" en switch
    };
    
    echo $resultado; // Imprime: Todo está bien.
    ?>
    ```
=== "Exemple amb números"
    ```php
    <?php
	
    $numero = 10;
    
    $resultado = match (true) {
        $numero < 0 => 'Número negativo',
        $numero === 0 => 'Es cero',
        $numero > 0 => 'Número positivo',
    };
    
    echo $resultado; // Imprime: Número positivo.
    ?>
    ```

## 4. Bucles

### 4.1. while

La instrucció **`while`** recorre un bloc de codi sempre que la condició especificada siga *vertadera*.

El bucle no s'executarà un nombre concret de vegades, sinó que verifica després de cada iteració si la condició continua sent *vertadera*.

La condició no ha de ser un comptador, podria ser l'estat d'una operació o qualsevol condició que s'avalue com a *vertadera* o *falsa*.

=== "Exemple while"
    ```php
    <?php
        $i = 1;
        while ($i <= 10) {
            echo "Línea " . $i . "<br/>";
            $i++;
        }
	?>
	```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova237.png" alt="prova 237" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.13: Exemple de sentència repetitiva while </figcaption></figure></div>


> Recorda **incrementar `$i`**, en cas contrari el bucle continuarà per sempre.

### 4.2. do-while

El bucle **`do-while`** sempre executarà el bloc de codi almenys una vegada, després verificarà la condició i repetirà el bucle mentre la condició especificada siga *vertadera*.

=== "Exemple do-while"
    ```php
    <?php
        do {
            $dado = rand(1, 6);
            // rand() devuelve un valor aleatorio
            echo "Tirando el dado... ";
            echo "ha salido un " . $dado . ".";
            echo "<br>";
        } while ($dado != 5);
        echo "¡Bien! Saco una ficha de casa.";
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova238.png" alt="prova 238" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.14: Exemple de sentència repetitiva do-while</figcaption></figure></div>


### 4.3. for

El bucle **`for`** s'utilitza quan se sap quantes vegades s'ha d'executar l'script.

=== "Exemple for"
    ```php
    <?php
        // Bucle ascendente
        for ($i = 1; $i <= 10; $i++) {
            echo "Línea " . $i;
            echo "<br>";
        }
        
        // Bucle descendente
        for ($i = 10; $i >= 0; $i--) {
            echo "Línea " . $i;
            echo "<br>";
        }
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova239.png" alt="prova 239" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.15: Exemple de sentència repetitiva for</figcaption></figure></div>

### 4.4. foreach

El bucle **`foreach`** recorre un bloc de codi per a cada element d'una matriu o cada propietat d'un objecte.

Un exemple comú d'este tipus de bucles és per a recórrer arrays.

=== "Exemple foreach"
    ```php
    <?php
        $diasSemana = array ("dilluns", "dimarts", "dimecres", "dijous", "divendres");

        foreach ($diasSemana as $item) {
            echo "$item <br>";
        }
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova240.png" alt="prova 240" style="zoom:100%;border: 2px solid #83abd4;"" /><figcaption class="figure-caption-small">🖼️ Figura 2.16: Exemple de sentència repetitiva foreach</figcaption></figure></div>

> Com veurem en el punt següent, **Arrays**, el bucle **`foreach`** s'utilitzarà també per a recórrer un tipus d'arrays anomenats **arrays associatius**.
> 

    
### 4.5. break i continue
*PHP*, de la mateixa manera que *Java* i *C*, permet trencar els bucles mitjançant la instrucció `break`. Al seu torn, `continue` permet botar a la iteració següent.

> **Si pots, evita `break` i `continue`**
> 
> No és desitjable usar-los. És preferible l'ús de variables *flag* per a controlar l'eixida dels bucles. 
>   
> === "Exemple de variable *flag*"
>     ```php
>     <?php
>         $salir = false;
>         for ($i = 1; $i <= 10 && !$salir; $i++) {
>             if ($i === 5) {
>                 echo "Salgo cuando i=5";
>                 $salir = true;
>             }
>         }
>     ?>
>     ```
> === "Resultat"
>     <div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova239b.png" alt="prova 239b" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.17: Exemple d'ús de variable flag per a substituir break o continue</figcaption></figure></div>
