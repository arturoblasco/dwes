# <img src="../../img/php_azul.svg" width="40"> 2.5. Funcions

Com que no es declaren els tipus de dades, els paràmetres de les funcions no tenen tipus ni s'indica el tipus de dada que retornen.

El **pas de paràmetres** es realitza **per valor**, és a dir, es fa una còpia de la variable.

```php
<?php
  function nombreFuncion($par1, $par2, ...) {
      // código
      return $valor;
  }

  $resultado = nombreFuncion($arg1, $arg2, …);
?>
```


=== "Exemple de funció"
    ```php
    <?php
      function diaSemana() {
          $semana = [ "lunes", "martes", "miércoles",
                      "jueves", "viernes", "sábado", "domingo" ];
          $dia = $semana[rand(0, 6)];
          return $dia;
      }

      $diaCine = diaSemana();
      echo "El próximo $diaCine voy al cine.";
    ?>
    ```

## 1. Paràmetres per referència

Si volem passar un paràmetre per referència, en la declaració de la funció indicarem els paràmetres mitjançant l'operador **`&`** per a indicar l'adreça de memòria de la variable.

=== "Exemple d'arguments per referència"
    ```php
    <?php
          function duplicarPorValor($argumento) {
                $argumento = $argumento * 2;
                echo "Dentro de la función: $argumento.<br>";
          }
          function duplicarPorReferencia(&$argumento) {
                $argumento = $argumento * 2;
                echo "Dentro de la función: $argumento.<br>";
          }

          $numero1 = 5;
          echo "Paso de parámetros por valor:<br/>";
          echo "Antes de llamar: $numero1.<br>";
          duplicarPorValor($numero1);
          echo "Después de llamar: $numero1.<br>";
          echo "<br>";
    
          $numero2 = 7;
          echo "Paso de parámetros por referencia:<br/>";
          echo "Antes de llamar: $numero2.<br>";
          duplicarPorReferencia($numero2);
          echo "Después de llamar: $numero2.<br>";
    ?>
    ```
=== "Resultat"

## 2. Paràmetres per defecte / opcionals

Permeten assignar valors en la declaració i, posteriorment, deixar l'argument en blanc.

=== "Exemple d'arguments per defecte"
    ```php
    <?php
       function obtenerCapital($pais = "todos") {
             $capitales = array("Italia" => "Roma",
                                "Francia" => "Paris",
                                "Portugal" => "Lisboa");

             if ($pais == "todos") {
                  return array_values($capitales);
             } else {
                  return $capitales[$pais];
             }
       }
    
       print_r(obtenerCapital());
       echo "<br/>";
       echo obtenerCapital("Francia");
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova253.png" alt="prova 253" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.25: Exemple de pas de paràmetres en funcions per referència</figcaption></figure></div>

En el cas de conviure amb altres tipus de paràmetres, els paràmetres que tenen el valor assignat per defecte sempre es col·loquen al final.

=== "Exemple d'ordre dels arguments"

    <?php
       function saluda($nombre, $prefijo = "Sr") {

       saluda("Aitor");

## 3. Paràmetres variables

Podem tindre funcions on en la declaració no indiquem la quantitat de dades d'entrada.

- `$cantidad` = **`func_num_args();`** → Obté la quantitat de paràmetres rebuts.
- `$arrayArgs` = **`func_get_args();`** → Obté un array amb els paràmetres.
- `$valor` = **`func_get_arg(numArgumento);`** → Obté el paràmetre que ocupa la posició `numArgumento`.

Estes funcions no es poden passar com a paràmetre a una altra funció (com a funcions variable, que veurem més avant). Per a fer-ho, hem de guardar prèviament la funció en una variable.


=== "Exemple d'arguments variables"
    ```php
    <?php
        function sumaParametros() {
            if (func_num_args() == 0) {
                return false;
            } else {
                $suma = 0;

                for ($i = 0; $i < func_num_args(); $i++) {
                    $suma += func_get_arg($i);
                }
    
                return $suma;
            }
        }
    
        echo sumaParametros(1, 5, 9); // 15
    ?>
    ```

### Variadics

Des de PHP 5.6, es pot utilitzar l'operador **`...`** (**variadics**), el qual "*disfressa*" els paràmetres com un array. Este operador es col·loca davant d'un paràmetre en la definició de la funció, i este paràmetre es convertirà en un **array** que contindrà tots els arguments addicionals passats a la funció:

=== "Exemple de *variadics*"

    ```php
    <?php
        function sumaParametrosMejor(...$numeros) {
            if (count($numeros) == 0) {
                return false;
            } else {
                $suma = 0;
                foreach ($numeros as $num) {
                	$suma += $num;
            	}
    
            return $suma;
            }
        }
    
        echo sumaParametrosMejor(1, 5, 9); // 15
    ?>
    ```
=== "Resultat"

## 4. Arguments amb nom

Des de PHP 8.0 podem passar els arguments amb el nom (a més de per posició, com hem fet fins ara). Els arguments amb nom es passen posant el nom com a prefix del paràmetre separat per dos punts: `$resultado = funcion( arg1 : valor1, arg2 : valor2 );`

Esta característica complementa els paràmetres opcionals i ens permet botar-ne el valor:


=== "Exemple d'arguments per nom"
    ```php
    <?php
        function funcionArgumentosNombre($a, $b = 2, $c = 4) {
            echo "$a $b $c";
        }

        funcionArgumentosNombre(c: 3, a: 1); // "1 2 3"
    ```
=== "Resultat"

=== "Exemple d'ordre dels arguments"

## 5. Funcions tipades

Des de PHP7, en les funcions, tant els **paràmetres** com el seu **valor de retorn** permeten la definició de tipus. Això es coneix com `strict_types` (tipificació estricta) i cal definir-ho en la primera línia de cada fitxer `.php` perquè el mateix intèrpret PHP comprove els tipus i llance errors si els tipus són incorrectes, mitjançant la sentència:

```php
<?php
 	declare(strict_types=1);
```

Així doncs, definirem els tipus dels paràmetres i dels valors retornats mitjançant els tipus: `int`, `float`, `string`, `bool`, `object` i `array`.

Si una funció no retorna res, s'indica mitjançant el tipus `void`.

=== "Exemple de funció tipada"
    ```php
    <?php
        declare(strict_types=1);

        function suma(int $a, int $b) : int {
            return $a + $b ;
        }
    
        $num = 33;
        echo suma(10, 30). "<br />";
        echo suma(10, $num). "<br />";
        echo suma("10", 30); // error por tipificación estricta, si no daría 40
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova259.png" alt="prova 259" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.32: Exemple de funció tipada</figcaption></figure></div>

???examplephp "Exemple 1"
    Què passa si enviem un número i una cadena sense utilitzar `strict`:
    ```php
    <?php
    declare(strict_types=1);

    function sumaNumeros(int $a, int $b) {
        return $a + $b;
    }

    // como `strict` no está habilitado la cadena "2 tablas" se convierte en int(2)
    // y el resultado devolverá 5
    echo sumaNumeros(3, "2 tablas");

    ?>
    ```
    
???examplephp "Exemple 2"
    Si volem retornar un valor d'un tipus diferent del dels arguments, haurem d'assegurar-nos que retorna el tipus correcte (en este exemple fent un *cast*):
    ```php
    <?php
    declare(strict_types=1);

    function sumaNumeros(float $a, float $b) : int {
        return (int) ($a + $b);
    }

    // el resultado devolverá 5
    echo sumaNumeros(3.3, 2.5);

    ?>
    ```

## 6. Abast

Les variables definides fora de les funcions tenen abast **global**: accessibles des de qualsevol funció.

Els paràmetres d'una funció i les variables declarades dins d'una funció (es coneixen com a variables **locals**) només són accessibles des de dins de la mateixa funció → abast de **funció**.

En cas de conflicte, tenen prioritat les variables locals. Per a evitar el conflicte, dins de la funció, podem declarar la variable com a `global`.

=== "Exemple d'abast local"
    ```php
    <?php
        function miCiudad() {
            $ciudad = "Elche";
            echo "Dentro de la función: $ciudad.<br>";
        }

        $ciudad = "Alicante";
        echo "Antes de la función: $ciudad.<br>";
        miCiudad();
        echo "Después de la función: $ciudad.<br>"
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova25a.png" alt="prova 25a" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.33: Exemple d'abast local de les variables</figcaption></figure></div>
<br/>
=== "Exemple d'abast global"
    ```php
    <?php
        function miCiudad() {
            global $ciudad;
            $ciudad = "Elche";
            echo "Dentro de la función: $ciudad.<br>";
        }

        $ciudad = "Alicante";
        echo "Antes de llamar: $ciudad.<br>";
        miCiudad();
        echo "Después de llamar: $ciudad.<br>"
    ?>
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova25b.png" alt="prova 25b" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.34: Exemple d'abast global de les variables</figcaption></figure></div>

!!!warning "No globals"
 	Cal evitar l'ús de variables globals dins de les funcions. En el cas de necessitar-les, és millor passar-les com a paràmetre a les funcions.

### 6.1. Ús de tipus `nullables` (PHP 7.1+)
Si necessites que un paràmetre o valor de retorn accepte *null*, pots usar l'operador **`?`** davant del tipus. Això indica que el valor pot ser del tipus especificat o *null*.
=== "Exemple de tipus *nullables*"
    ```php
    <?php
    function obtenerNombre(?string $nombre): string {
        return $nombre ? $nombre : "Invitado";
    }

    echo obtenerNombre(null); // Imprime "Invitado"
    echo obtenerNombre("Juan"); // Imprime "Juan"
    ```
=== "Resultat"
	En este cas, el paràmetre `$nombre` pot ser un `string` o `null`. Si és null, la funció retorna "Invitado".

### 6.2. Tipus unió (PHP 8.0+)
PHP 8.0 va introduir els **tipus unió**, que permeten que un paràmetre o valor de retorn puga ser de diversos tipus alhora.
=== "Exemples d'unió de tipus"
    ```php
    <?php
        function obtenerValor(int|string $valor): string {
        	return (string) $valor;
    	}
	
    	echo obtenerValor(10);     // Imprime "10"
    	echo obtenerValor("diez"); // Imprime "diez"
    ```
=== "Resultat"
	En este cas, el paràmetre `$valor` pot ser un `int` o un `string`.

## 7. Funcions variable

- Permet assignar una funció a una variable.
- Nom de la funció entre cometes.
- Si una variable va seguida de parèntesis, PHP buscarà una funció amb el seu valor.

=== "Sintaxi"
    ```php
    <?php
        $nombreFuncion = 'nombreDeLaFuncion';
		$nombreFuncion(); // Llama a nombreDeLaFuncion()
    ```
=== "Exemple"
	```php
    <?php
    	function sumar ($a, $b){
    		return $a + $b;
    	}
        $funcion = "sumar";
        echo $funcion(3,4); // invoca a la función suma
    ?>
    ```
=== "Resultat"
	Ací, la variable `$operacion` emmagatzema el nom de la funció `sumar`, i en cridar-la amb els arguments (3, 4), realitza l'operació i retorna el resultat.

!!!note "Funcions anònimes"
 	PHP permet la definició i l'ús de funcions anònimes, és a dir, funcions que no tenen nom, i s'utilitzen principalment per a gestionar els *callbacks*. Este tipus de funcions s'utilitza molt en **Javascript** per a gestionar els esdeveniments i les promeses.
 	
    === "Exemple de funció anònima"
        ```php
        <?php
            $anonima = function() {
                echo "Hola"."<br/>";
            };
            $anonima();
    
            $anonimaConParametro = function($nombre) {
                echo "Hola ".$nombre."<br/>";
            };
            $anonimaConParametro("Aitor");
    
            // Uso de variables externas a la función anónima --> `use`
            $mensaje = "Hola";
            $miClosure = function() use ($mensaje) {
                echo $mensaje."<br/>";;
            };
            $miClosure();
    
            // Uso de parámetros
            $holaPHP = function($arg) use ($mensaje) {
                echo $mensaje." ".$arg;
            };
            $holaPHP("PHP");
        ?>
        ```
    === "Resultat"
        <div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova25c.png" alt="prova 25c" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.35: Exemples d'ús de funció anònima en php</figcaption></figure></div>

## 8. Biblioteca de funcions

Podem agrupar un conjunt de funcions en un fitxer, per a permetre'n la reutilització. Posteriorment, s'inclou amb:

- **`include(archivo);`**   |   **`include_once(archivo);`**
- **`require(archivo);`**   |   **`require_once(archivo);`**

Si no troba el fitxer, `require` llança un error fatal, `include` l'ignora.

Les funcions `_once` només es carreguen una vegada: si ja s'ha inclòs prèviament, no ho torna a fer, i s'eviten bucles.

Per exemple, col·loquem les funcions en el fitxer `biblioteca.php` i posteriorment en un altre fitxer s'hi fa referència:

=== "`biblioteca.php`"
    ```php
    <?php
        function suma(int $a, int $b) : int {
            return $a + $b;
        }

        function resta(int $a, int $b) : int {
            return $a - $b;
        }
    ?>
    ```
=== "Php"
    ```php
    <?php
        include_once("biblioteca.php");
        echo suma(10,20);
        echo resta(40,20);
    ?>
    ```

## 9. Plantilles mitjançant include

Mitjançant l'ús de la instrucció `include` també podem separar fragments de codi PHP/HTML que vulguem reutilitzar en els nostres llocs web i crear un sistema molt senzill de plantilles.

Per exemple, separarem una pàgina en tres parts:

=== "Part superior en `header.php`"
    ```php
    <!DOCTYPE html>
    <html lang="es">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title><?= $titulo ?></title>
    </head>
    <body>
    ```
=== "Part inferior en `footer.html`"
    ```html
        <footer>Profesor/a X</footer>
    </body>
    </html>
    ```
=== "Pàgina utilitzant *include*"
    I després ens centrem únicament en el contingut que canvia en `pagina.php`:

    ```php
    <?php
        $titulo = "Página con includes";
        include("header.php");
    ?>

    <h1><?= $titulo ?></h1>
    
    <?php
        include("footer.html");
    ?>
    ```
