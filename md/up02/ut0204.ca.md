# 1. Arrays indexats
Per a emmagatzemar dades compostes, podem utilitzar tant arrays senzills com arrays associatius (semblants a un **mapa**). En realitat tots els arrays són mapes ordenats compostos de parells *clau-valor*.

 De la mateixa manera que en *Java*, es definixen mitjançant claudàtors, són *0-index*, i es pot assignar un valor a una posició determinada:

```php
<?php
	// crear array: opción 1
	$frutas = array("naranja", "pera", "manzana");
	
	// crear array: opción 2
	$frutas2 = ["naranja", "pera", "manzana"];
	
	// crear array vacía: opción 3
	$frutas3 = [];
    // asignar valores
	$frutas3[0] = "naranja";
	$frutas3[1] = "pera";
	$frutas3[] = "manzana"; // lo añade al final
```

!!!warning "**Compte amb mesclar tipus**"
	Com que el tipat és dinàmic, els nostres arrays poden contindre dades de diferents tipus. 
    
    No es recomana mesclar els tipus.
    ```php
    <?php
    function miFuncion() {
        echo "Vamos al cole.";
    }

    $miArray = array("Alba", 3, ["manzanas", "bananas"], miFuncion());

    $miArray[3];
    ?>
    ```

Podem obtindre la grandària de l'array mitjançant la funció `count(array)`. Per a recórrer l'array farem ús d'un bucle `for`:

=== "Exemple de recorregut d'*array*"
    ```php
    <?php
        $tam = count($frutas); // tamaño del array

        for ($i=0; $i<count($frutas); $i++) {
            echo "Elemento $i: $frutas[$i] <br />";
        }
    ```

Una altra manera de recórrer els arrays, fins i tot més elegant, és fer ús de `foreach`. La seua sintaxi és `foreach (array as elemento)`:

=== "Exemple de recorregut d'*array* amb *foreach*"
    ```php
    <?php
        // mediante foreach no necesitamos saber el tamaño del array
        foreach ($frutas as $elemento) {
            echo "$elemento <br />";
        }
    ```

# 2. Arrays associatius

Cada element és un parell *clau-valor*. En compte d'accedir per la posició, ho fem mitjançant una clau. Així doncs, per a cada clau s'emmagatzema un valor.

S'assigna de la manera següent dins dels claudàtors: `clave => valor`.

A l'hora de recórrer este tipus d'arrays, mitjançant `foreach` separem cada element en una parella clau => valor:

=== "Exemple d'*array associatiu*"
    ```php
    <?php
        $capitales = ["Italia" => "Roma",
                    "Francia" => "Paris",
                    "Portugal" => "Lisboa"];

        // 1) Acceder al elemento por la clave, no la posición
        $capitalFrancia = $capitales["Francia"]; 
    
        // 2) Añadir un elemento
        $capitales["Alemania"] = "Berlín"; 
    
        // 3) Mostrar valor de una variable
        echo "La capital de Francia es $capitalFrancia <br />";
        // 4) Mostrar valor de un elemento del array por {}
        echo "La capital de Francia es {$capitales["Francia"]} <br />";
    
        // 5) Añadir con clave 0 ¡¡¡NO ASIGNAR VALORES SIN CLAVE!!!
        $capitales[] = "Madrid";
    
        // 6) Recorrer array asociativo y mostrar valores
        foreach ($capitales as $valor) {
            echo "$valor <br />";
        }
    
        // 7) Recorrer array asociativo y mostrar clave y valor
        foreach ($capitales as $pais => $ciudad) { 
            echo "$pais : $ciudad <br />";
        }
    ```

## 3. Arrays bidimensionals

Consistix en un array d'arrays, ja siguen arrays seqüencials o associatius. Hi pot haver *N* dimensions.

=== "Exemple d'*array bidimensional*"
    ```php
    <?php
        $persona["nombre"] = "Bruce Wayne";
        $persona["telefonos"] = ["966 123 456", "636 636 636"]; // array de arrays ordinarios
        $persona["profesion"] = ["dia" => "filántropo", "noche" => "caballero oscuro"]; // array de arrays asociativos

        echo $persona['nombre']." por la noche trabaja de ".$persona['profesion']['noche'];
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova243.png" alt="prova 243" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.21: Exemple d'ús d'array de dues dimensions</figcaption></figure></div>

Combinant els arrays associatius en diverses dimensions podem emmagatzemar la informació com si fora una taula:

=== "Exemple d'*array bidimensional* anàleg a una taula"
    ```php
    <?php
        $menu1 = [ "Plato1" => "Macarrones con queso", 
                   "Plato2" => "Pescado asado", 
                   "Bebida" => "Coca-Cola", 
                   "Postre" => "Helado de vainilla" ];
        $menu2 = [ "Plato1" => "Sopa", 
                   "Plato2" => "Lomo con patatas", 
                   "Bebida" => "Agua", 
                   "Postre" => "Arroz con leche" ];
        
        // Crear un array a partir de arrays asociativos
        $menus = [$menu1, $menu2]; 

        echo "Menú del día<br/>";
        $cont = 0;
        foreach ($menus as $menudeldia) {
            echo "<br />Menú ".++$cont."<br />";
    
            foreach ($menudeldia as $platos => $comida) {
                echo "$platos: $comida <br/>";
            }
        }
    
        // Para acceder a un elemento concreto se anidan los corchetes
        $postre0 = $menus[0]["Postre"];
    ```
=== "Resultat"
	<div style="text-align: center;"><figure><img src="../../img/ut02/ut02_prova244.png" alt="prova 244" style="zoom:100%;border: 2px solid #83abd4;" /><figcaption class="figure-caption-small">🖼️ Figura 2.22: Exemple de la semblança dels arrays associatius amb les taules</figcaption></figure></div>

Encara que puga paréixer una bona idea crear este tipus d'estructures, és **millor utilitzar objectes** conjuntament amb arrays (possiblement arrays d'altres objectes) per a crear estructures complexes que permeten modelar millor els problemes.
