<div style="text-align: center;"><img src="../../img/ut02/php_logo.png" style=" max-width: 30%;" /></div>

- Acrònim de **P**ersonal **H**ome **P**age.
- Llenguatge de propòsit general, encara que el seu fort és el desenvolupament web.
- Sintaxi semblant a *C* / *Java*.
- El codi s'executa en el servidor (en *Apache* mitjançant `mod_php`).
- El client rep el resultat generat després d'interpretar el codi en el servidor.
- El codi s'emmagatzema en fitxers amb extensió **`.php`**.

La versió actual (*a data de setembre de 2026*) és la **8.5.10**. A més de nombroses funcionalitats noves que anirem veient durant el curs, té més de dues vegades millor rendiment que PHP5.

La seua documentació és extensa i està traduïda: [**https://www.php.net/manual/es/**](https://www.php.net/manual/es/){:target="_blank"}.

> **Versió de php**
> 
> Per a comprovar la teua versió de php pots utilitzar la funció `phpversion()`:
> ```php
> <?php
> echo phpversion(); 
> ?>
> ```


## 1. Codi incrustat

Els blocs de codi s'escriuen entre **`<?php`** i **`?>`**.

Les sentències se separen mitjançant **` ; `**.

!!!examplephp "Exemple en php"
    === "Codi"	
        ```php
        <!DOCTYPE html>
        <html lang="es">
        <head>
          <meta charset="UTF-8">
          <title>PHP fácil</title>
        </head>
        <body>
          <!-- Muestra una frase con HTML -->
          Hola mundo<br>
          <!-- Muestra una frase con PHP -->
          <?php echo "Es muy fácil programar en PHP."; ?>
        </body>
        </html>
        ```
    === "Resultat"

## 2. Generant codi

Tenim tres possibilitats a l'hora de generar contingut en els nostres documents PHP:

- `echo expresión;`
- `<?= expresión ?>`
- `print (expresión);`

Les que utilitzarem són:

- `echo` quan ho fem dins d'un bloc d'instruccions i 
- `<?=` quan només mostrem el valor d'una variable dins d'un fragment HTML.

!!!examplephp "Exemple en php"
    === "Codi"	
        ```php
        <!DOCTYPE html>
        <html lang="es">
        <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">
          <title>Echo y print</title>
        </head>
        <body>
          <p><?php echo "Este texto se mostrará en la página web."; ?></p>
          <p><?= "Este texto se mostrará en la página web." ?></p><br>
          <p><?php print("Este texto se mostrará en la página web."); ?></p>
        </body>
        </html>
        ```

## 5. Variables

- No cal declarar-les prèviament.
- Comencen per **`$`**, per exemple `$nombre`, seguit d'un caràcter en lletra minúscula (**recomanació**) o guió baix **`_`**. Després ja es poden posar números.
- Són *case sensitive*: `$var != $vAR`.
- No es declara el seu tipus, el tipat és dinàmic. S'assigna en temps d'execució depenent del valor assignat.
- Convenient: cal inicialitzar-les, si no donen error.

!!!examplephp "Exemple de variables"
    === "Codi"
        ```php
        <?php
            $nombre = "Marta";
            $nombreCompleto = "Marta López";
            $numero = 123;
            $numero2 = 456;
            $pi = 3.14;
            $suerte = true;
            $sinValor;
            $_1 = "el primero";
        

            echo $sinValor;
        ?>
        ```

### 5.1. Tipus de dades
Encara que a priori no hi ha tipus de dades, internament PHP treballa amb:
 	
- quatre tipus escalars: *bool*, *int*, *float* i *string,*
- quatre tipus compostos: *array*, *object*, *callable* i *iterable*
- Existix un tipus especial per a *null* (més informació [**ací**](http://php.net/manual/es/language.types.null.php){:target="_blank"}).

> **Com obtindre el tipus de dades**
> 
> Per a obtindre el tipus de dades d'una variable utilitza la funció `var_dump()`
> ```php
> <?php
>   $x = 2;
>   var_dump($x);
> 
>   var_dump(8);
>   var_dump("Alba");
>   var_dump(3.14);
>   var_dump(true);
>   var_dump([1, "hola", null]);
>   var_dump(NULL);
> ?>
> ```

### 5.2. Abast
En PHP, les variables es poden declarar en qualsevol part de l'script.

L'abast d'una variable és la part de l'script on es pot fer referència a la variable o utilitzar-la.

PHP té tres abasts de variables diferents:

- local
- global
- estàtic

!!!examplephp "Exemple d'abasts"
    === "Abast global"
        Una variable declarada **fora de** una funció té un **àmbit global** i només s'hi pot accedir fora d'una funció:

        ```php
        <?php
        $x = 5; // global

        function miTest() {
          // usar x dentro de esta función generará un error
          echo "<p>Variable x dentro de función es: $x</p>";
        }
        miTest();

        echo "<p>Variable x fuera de función es: $x</p>";
        ?>
        ```

    === "Abast local"
        Una variable declarada **dins de** una funció té un **àmbit local** i només s'hi pot accedir dins d'eixa funció:

        ```php
        <?php
        function miTest() {
          $x = 5; // local
          echo "<p>Variable x dentro de función es: $x</p>";
        }
        miTest();

        // usar x fuera de la función generará un error
        echo "<p>Variable x fuera de función es: $x</p>";
        ?>
        ```

    === "Estàtica"
        ```php
        <?php

        function contador() {
            static $numero = 0;

            $numero++;

            echo $numero . "<br>";
        }

        contador();
        contador();
        contador();

        ?>
        El resultado sería:
        ```bash
        1
        2
        3
        ```

## 6. Constants

Són variables el valor de les quals no varia.

Hi ha dues possibilitats:

- `define(NOMBRE, valor);`
- `const NOMBRE;      // a partir de PHP 5.3`

!!!examplephp "Exemple de constants"
    === "Codi"
        ```php
        <?php
              define("PI", 3.1416);
              const IVA = 0.21;
        
              echo PI, " ", IVA; // No se pone el símbolo dolar
        ?>
        ```
    === "Resultat"
