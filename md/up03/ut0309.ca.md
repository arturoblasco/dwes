# <img src="../../img/php_azul.svg" width="40"> 3.9. Classes final

Són classes oposades a les classes abstractes, ja que eviten que es puga heretar una classe o mètode per a sobreescriure'l. 

Es definix mitjançant **`final`**` class NombreClase {}`.

```php
<?php
  // clase Producto
  class Producto {
    private $codigo;

    public function getCodigo() : string {
        return $this->codigo;
    }

    final public function mostrarResumen() : string {
        return "Producto ".$this->codigo;
    }
  }

  // clase Microondas
  // No podremos heredar de Microondas
  final class Microondas extends Producto {
    private $potencia;

    public function getPotencia() : int {
        return $this->potencia;
    }

    // No podemos implementar mostrarResumen()
  }
```
