# <img src="../../img/php_azul.svg" width="40"> 3.11. Mètodes encadenats

Seguix el plantejament de la programació funcional, i també es coneix com a **method chaining**. Planteja que sobre un objecte es realitzen diverses crides; és a dir, consistix a cridar diversos mètodes d'un objecte en una mateixa línia, n'hi ha prou amb afegir al final de cada mètode: **`return $this;`**.

???examplephp "Exemple de mètodes encadenats"
    Per a facilitar-ho, modificarem tots els seus mètodes mutadors (que *modifiquen dades*, *setters*, ...) perquè retornen una referència a `$this`:

    === "Php"
        ```php hl_lines="5 10 16"
        <?php
        class Coche {
                public function lavar(){
                    echo "Coche lavado.\n";
                    return $this;  // retorna el mismo objeto Coche
                }
        
                public function encerar(){
                    echo "Coche encerado.\n";
                    return $this;  // retorna el mismo objeto Coche
                }
        }
        
        // ejemplo llamada a los métodos encadenados	
        $coche = new Coche;
        $coche->lavar()->encerar();
        ```
    === "Resultat"
        ```sh
        // mostrará
        Coche lavado.
        Coche encerado.
        ```
???examplephp "Un altre exemple"
    ```php hl_lines="11 19 37 38 39"
    <?php
    class Libro {
        private string $nombre;
        private string $autor;

        public function getNombre() : string {
            return $this->nombre;
        }
        public function setNombre(string $nombre) : Libro { 
            $this->nombre = $nombre;
            return $this;
        }

        public function getAutor() : string {
            return $this->autor;
        }
        public function setAutor(string $autor) : Libro {
            $this->autor = $autor;
            return $this;
        }

        public function __toString() : string {
            return $this->nombre." de ".$this->autor;
        }
    }

    echo "USO TRADICIONAL:<br/>"
    $libro = new Libro();
    $libro->setNombre("Cien años de soledad");
    $libro->setAutor("Gabriel García Márquez");

    echo $libro; // Cien años de soledad de Gabriel García Márquez

    echo "<br/>################<br/>";

    echo "USO DE MÉTODOS ENCADENADOS:<br/>"
    $libro = (new Libro())
            ->setNombre("1984")
            ->setAutor("George Orwell");

    echo $libro; // Retorna el método __toString() . Resultado: 1984 de George Orwell
    ```
