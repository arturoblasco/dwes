# <img src="../../img/php_azul.svg" width="40"> 3.4. Constructor

El constructor dels objectes es definix mitjançant el mètode màgic **`__construct`**.

!!!warning "Un sol constructor"
	El mètode `__construct` pot tindre o no paràmetres, però **només hi pot haver un únic constructor**.

```php
<?php
  class Persona {
     private string $nombre;

     public function __construct(string $nom) {
         $this->nombre = $nom;
     }

     public function imprimir(){
       echo $this->nombre . PHP_EOL;
     }
  }

  $bruno = new Persona("Bruno Díaz");
  $bruno->imprimir();
```

## Constructors en PHP8

Una de les grans novetats que oferix PHP 8 és la simplificació dels constructors amb paràmetres, el que es coneix com a **promoció dels *atributs del constructor***.

Per a això, en compte d'haver de declarar els atributs com a privats o protegits, i després dins del constructor haver d'assignar els paràmetres a estos atributs, el mateix constructor promociona els atributs.

??? examplephp "Exemple PHP7 o anteriors VS PHP8"
	Imaginem una classe `Punto` on vulguem emmagatzemar les seues coordenades:

	=== "Amb PHP7 o anteriors"
		```php
		<?php
			class Punto {
				protected float $x;
				protected float $y;
				protected float $z;
			
				public function __construct(float $x = 0.0,
											float $y = 0.0,
											float $z = 0.0 )
				{
					$this->x = $x;
					$this->y = $y;
					$this->z = $z;
				}
			}
		```
	=== "PHP8"
		Quedaria de la manera següent (molt més curt, cosa que facilita la seua llegibilitat):
		
		```php
		<?php
			class Punto {
				public function __construct(protected float $x = 0.0,
											protected float $y = 0.0,
											protected float $z = 0.0,) 
				{}
			}
		```
> **L'ordre importa**
> 
> A l'hora de codificar una classe l'ordre dels elements ha de ser:
> ```php
> <?php
> declare(strict_types=1);
> 
> class NombreClase {
> // atributos
> 
> // constructor
>    
> // getters - setters
> 
> // resto de métodos
>     
> }
> ```
