# <img src="../../img/php_azul.svg" width="40"> 3.13. Espai de noms

Des de PHP 5.3, i també coneguts com a *Namespaces*, permeten organitzar les classes, interfícies, funcions i constants en un àmbit separat. Això evita col·lisions o conflictes de noms entre diferents elements, com ocorre en altres llenguatges (per exemple, els paquets en Java).

## 1. Per què usar `namespaces`

???examplephp "Exemple de per què usar `namespaces`"
    Imagina't que tenim el codi següent:
    ```php
    <?php
        class Producto {
            public $nombre;
        }
    	
    	class Producto {
            public $nombre;
        }
    ```
    
    Este codi donaria error perquè hi ha dues classes amb el mateix nom. Això provoca un conflicte i PHP no sap quina de les dues classes utilitzar.<br/><br/>
    Amb `namespaces` l'exemple anterior podria quedar:
    
    ```php
    <?php
        namespace Tienda\Alimentos;
        class Producto {
            public $nombre;
        }
    ```
    ```php
    <?php    
        namespace Tienda\Electronica;
        class Producto {
            public $nombre;
        }
    ```
    Ací, en estar en *namespaces* diferents, ambdues classes `Producto` poden coexistir sense problemes.


Els *namespaces* permeten:

- Evitar conflictes de nom en reutilitzar llibreries o frameworks.
- Millorar l'estructura i l'organització del teu codi.
- Facilitar la col·laboració en projectes grans.

> **Recomanació**
> 
> Mantín un sol *namespace* per fitxer i organitza els fitxers en una estructura de carpetes que reflectisca els diferents nivells dels namespaces, de manera semblant a com s'organitzen els paquets en Java.

## 2. Declaració d'un namespace

Un *namespace* es declara en la primera línia del fitxer usant la paraula clau `namespace` seguida del nom de l'espai de noms. Els nivells d'un *namespace* se separen amb barres invertides `\`.

???examplephp "Exemple `namespace`"
    En l'exemple següent, la classe `Producto` que es troba en el fitxer **`Producto.php`** i la constant `IVA` pertanyen al *namespace* `Dwes\Ejemplos`.

    ```php
    <?php
    // fichero Producto.php
        namespace Dwes\Ejemplos;
        
        const IVA = 0.21;
    
        class Producto {
            public $nombre;
    
            public function muestra(): void {
                echo "<p>Producto: " . $this->nombre . "</p>";
            }
        }
    ```

## 3. Tipus d'accés als recursos en namespaces

Per a accedir a recursos dins d'un *namespace*, cal incloure'ls primer en el fitxer, usant `include` o `require`. Depenent de la ubicació del recurs, hi ha tres tipus d'accés:

A) **Sense qualificar**: Es referix directament al recurs si està en el mateix *namespace*.

???examplephp "Exemple d'accés sense qualificar"
	
    ```php
    <?php
    namespace MiNamespace;
    
    class MiClase {
        public function mostrar() {
            echo "Esto es MiClase";
        }
    }
    
    // Como MiClase está en el mismo namespace (MiNamespace),
    // puedo crear una instancia sin especificar el namespace completo.
    $miObjeto = new MiClase();  // Acceso sin cualificar
    $miObjeto->mostrar();
    ```

B) **Qualificat**: Usa una ruta relativa dins del mateix namespace o subnamespace (`rutaRelativa\recurso`)→ no cal posar el *namespace* complet.
???examplephp "Exemple d'accés qualificat"
	
    ```php
    <?php
    namespace MiNamespace\SubNamespace;
  
    class ClaseSecundaria {
        public function mostrar() {
            echo "Esto es ClaseSecundaria en SubNamespace";
        }
    }
	```

    ```php
    <?php    
    namespace MiNamespace;
	
    class MiClase {
        public function mostrar() {
            echo "Esto es MiClase en MiNamespace";
        }
    }
	
    // Como ClaseSecundaria está en un subnamespace de MiNamespace,
    // puedo usar el nombre cualificado sin poner la barra inicial.
    $secundaria = new SubNamespace\ClaseSecundaria();  // Acceso cualificado
    $secundaria->mostrar();
    ```

C) **Totalment qualificat**: Usa la ruta completa des de l'arrel del *namespace* ( `\rutaAbsoluta\recurso`)

???examplephp "Exemple d'accés totalment qualificat"
	```php
    <?php
    namespace OtroNamespace;
	
    class ClaseExterna {
        public function mostrar() {
            echo "Esto es ClaseExterna en OtroNamespace";
        }
    }
    ```

    ```php
    <?php
    namespace MiNamespace;
	
    class MiClase {
        public function mostrar() {
            echo "Esto es MiClase en MiNamespace";
        }
    }
	
    // Como ClaseExterna está en un namespace completamente diferente,
    // necesitamos usar el namespace completo y comenzar con una barra invertida.
    $externa = new \OtroNamespace\ClaseExterna();  // Acceso totalmente cualificado
    $externa->mostrar();
	```

???examplephp "Exemple d'accés"
	```php
    <?php
    namespace Dwes\Ejemplos;

    include_once("Producto.php");
    
    // acceso sin cualificar (está en el mismo namespace)
    echo IVA;   // imprime 0,21
    
    // acceso cualificado (error si Utilidades no existe)
    echo Utilidades\IVA;	   // Error, Utilidades no está definido
    
    // acceso totalmente cualificado
    echo \Dwes\Ejemplos\IVA; // Correcto
    
    $p1 = new Producto();
    // busca la clase en el mismo namespace y
    // encuentra \Dwes\Ejemplos\Producto
    
    $p2 = new Model\Producto();
    // daría error, no existe el namespace Model.
    // Está buscando \Dwes\Ejemplos\Model\Producto
    
    $p3 = new \Dwes\Ejemplos\Producto();
    // \Dwes\Ejemplos\Producto
    ```

### 3.1. Resum dels tipus d'accés

| Tipus d'accés              | Exemple d'ús                          | Descripció                                                   |
| -------------------------- | ------------------------------------- | ------------------------------------------------------------ |
| **Sense qualificar**       | `new MiClase();`                      | S'usa quan el recurs està en el mateix *namespace*.          |
| **Qualificat**             | `new SubNamespace\ClaseSecundaria();` | S'usa una ruta **relativa** si el recurs està en un subnamespace o en el mateix *namespace*. |
| **Totalment qualificat**   | `new \OtroNamespace\ClaseExterna();`  | S'usa la **ruta completa** des de l'arrel del *namespace*, amb una barra inicial `\`. |

### 3.2. `use`

Per a evitar la necessitat d'escriure *rutes qualificades* o *totalment qualificades* constantment, PHP permet declarar l'ús de recursos d'altres *namespaces* mitjançant la paraula clau `use`, de manera semblant a l'`import` en Java.

### 3.3. Formes d'utilitzar `use`

- **Usar constants**: `use const nombreCualificadoConstante`
- **Usar funcions**: `use function nombreCualificadoFuncion`
- **Usar classes**: `use nombreCualificadoClase`
- **Àlies de la classe**: `use nombreCualificadoClase as NuevoNombre` (canviar el nom per a evitar conflictes).

???examplephp "Exemple de `use`"
    Si volem utilitzar la classe `\Dwes\Ejemplos\Producto` en un fitxer en l'arrel, per exemple `inicio.php`, ho faríem així:

    ```php
    <?php
        include_once("Dwes\Ejemplo\Producto.php");
    
        use const Dwes\Ejemplos\IVA;  // uso de constante
        use \Dwes\Ejemplos\Producto;  // uso de clase
    
        echo IVA;  // imprime 0,21
        $p1 = new Producto();  // no se necesita la ruta completa, gracias a `use`
    ```

???examplephp "Exemple d'àlies"
    ```php
    <?php
        use App\Modelos\Producto as ProductoAlimentos;
        use Tienda\Electronica\Producto as ProductoElectronico;

        $p1 = new ProductoAlimentos();
        $p2 = new ProductoElectronico();
    ```

> **Ús de `use`**
> 
> L'ús de `use` només és necessari per a accedir a recursos que estan en un *namespace* diferent. Si estàs treballant dins del mateix *namespace*, no és necessari.

## 4. Organització de projectes amb namespaces

A mesura que un projecte creix, és fonamental organitzar el codi font de forma estructurada. Una recomanació comuna és col·locar els fitxers que interactuen amb el navegador en l'arrel del projecte i organitzar les classes dins d'un namespace en una carpeta específica, com `src` o `app`.

<div style="text-align: center;"><figure><img src="../../img/ut03/img02.png" style="max-width:100%;" /><figcaption class="figure-caption-small">🖼️ Figura 3.2: Exemple d'organització de projectes usant namespace</figcaption></figure></div>

**Regles d'organització**:

1. **Un recurs per fitxer**: Cada classe, funció o constant ha d'estar en el seu propi fitxer.
2. **Incloure namespaces**: Declara el namespace en la primera línia del fitxer (si no està en el directori arrel).
3. **Usar `include_once`**: Per a carregar els recursos necessaris (classes, interfícies, etc.).
4. **Declarar dependències**: Cada recurs ha d'incloure les dependències que necessita, com ara classes base o interfícies.
5. **Ús de `use`**: Si el recurs està en un namespace diferent, utilitza `use` per a facilitar l'accés sense qualificar.

???examplephp "Exemple d'organització de fitxers"
    ```sh
    /index.php
    /app/Modelos/Usuario.php
    /app/Modelos/Producto.php
    ```

Cada fitxer ha d'incloure el seu *namespace* corresponent:

???examplephp "Exemple d'estructura"
	
    ```php
        <?php
        // /app/Modelos/Usuario.php			
        namespace App\Modelos;
    
        class Usuario {
            public $nombre;
        }
    ```
    
    ```php
        <?php
        // /app/Modelos/Producto.php
        namespace App\Modelos;
    
        class Producto {
            public $nombre
        }
    ```

???examplephp "Exemple d'accés a classes"
    ```php
    <?php
        include_once "app/Modelos/Usuario.php";
        include_once "app/Modelos/Producto.php";

        use App\Modelos\Usuario;
        use App\Modelos\Producto;
    
        $usuario = new Usuario();
        $producto = new Producto();
    ```



## 5. Autoload: càrrega automàtica de classes

Per a evitar la necessitat d'usar `include_once` o `require` en cada fitxer, PHP oferix l'autoload, que permet carregar classes automàticament quan són necessàries. Això es fa mitjançant la funció `spl_autoload_register`.

???examplephp "Exemple d'autoload"
    ```php
    <?php
        spl_autoload_register(function($nombreClase) {
            include_once $nombreClase . '.php';
        });

        $producto = new App\Modelos\Producto();  // Autocarga Producto.php
    ```

### 5.1. Organització amb autoload

I com organitzem ara el nostre codi aprofitant l'autoload?

<div style="text-align: center;"><figure><img src="../../img/ut03/img03.png" alt="img03" style="zoom:75%;" /><figcaption class="figure-caption-small">🖼️ Figura 3.3: Ordenar classes en una carpeta (app)</figcaption></figure></div>

Una bona pràctica és organitzar totes les classes dins d'una carpeta com `app`. Després, l'autoload es configura per a buscar classes dins d'esta carpeta:

???examplephp "Exemple d'estructura de directoris"
    ```sh
    /index.php
    /app/Modelos/Usuario.php
    /app/Modelos/Producto.php
    /autoload.php
    ```
???examplephp "Exemple d'autoload en el fitxer  `autoload.php`"
    ```php
    <?php
        spl_autoload_register(function($nombreClase) {
            $ruta = __DIR__ . "/" . $nombreClase . '.php';
            $ruta = str_replace("\\", "/", $ruta);
            
            // Verifica si el archivo existe antes de incluirlo
            if (file_exists($ruta)) {
                include_once $ruta;
            } else {
                die("No se pudo cargar la clase: $nombreClase");
            }
        });
    ```


???examplephp "Exemple d'ús d'autoload en el fitxer principal"
    ```php
    <?php
        // /index.php
        include_once "autoload.php";

        use App\Modelos\Producto;
        use App\Modelos\Usuario;
    
        $usuario = new Usuario();
        $producto = new Producto();
    ```
