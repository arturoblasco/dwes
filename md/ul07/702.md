# <img src="../../img/laravel_azul.svg" width="40"> 11.2. Consumo desde Vue

En este apartado creamos la SPA en Vue que se conecta a la API del apartado 11.1: login, lista de notas, creación con errores de validación y logout.

!!!tenencuenta "Requisitos"
    * La API `testear` funcionando en `http://testear.test` (con Sail, `http://localhost`).
    * **Node.js** 20 o superior (`node -v`).
    * Conocimientos básicos de Vue (componentes, `ref`, `v-if`, `v-for`, `v-model`), que se trabajan en DWEC.

## 1. Crear el proyecto Vue

Fuera de la carpeta del proyecto Laravel:

```bash
npm create vite@latest notas-vue -- --template vue
cd notas-vue
npm install
npm install axios
```

Estructura que usaremos:

```text
notas-vue/
├── vite.config.js          # proxy hacia Laravel
└── src/
    ├── main.js
    ├── App.vue             # muestra el login o las notas
    ├── services/
    │   ├── api.js          # instancia de axios
    │   ├── auth.js         # csrf, login, logout, usuario actual
    │   └── notes.js        # peticiones de notas
    └── components/
        ├── LoginForm.vue
        └── NotesPanel.vue
```

## 2. Proxy de desarrollo

En `vite.config.js`:

```js
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

// Dirección de la API Laravel. Con Sail: "http://localhost"
const backend = "http://testear.test";

export default defineConfig({
    plugins: [vue()],
    server: {
        proxy: {
            "/api": { target: backend, changeOrigin: true },
            "/sanctum": { target: backend, changeOrigin: true },
        },
    },
});
```

Todas las peticiones de la SPA a `/api/...` y `/sanctum/...` se reenvían a Laravel. Para el navegador, la SPA y la API están en `http://localhost:5173`: las cookies funcionan y no hay CORS (apartado 11.1).

!!!tenencuenta "Usa siempre rutas relativas"
    En el código Vue escribe `/api/notes`, **nunca** `http://testear.test/api/notes`. Si pones la URL completa, la petición se salta el proxy y vuelven los problemas de cookies y CORS.

## 3. Servicios

### 3.1. Instancia de axios: `src/services/api.js`

```js
import axios from "axios";

export const api = axios.create({
    headers: { Accept: "application/json" },
    withCredentials: true,   // envía las cookies de sesión
    withXSRFToken: true,     // envía la cabecera X-XSRF-TOKEN
});
```

* `Accept: application/json`: Laravel responde siempre en JSON (apartado 10.1).
* `withCredentials` y `withXSRFToken`: con el proxy, la SPA y la API comparten origen y axios ya enviaría la cookie y la cabecera CSRF. Las dejamos activadas porque son **imprescindibles** si algún día la SPA y la API están en orígenes distintos (por ejemplo, `app.midominio.com` y `api.midominio.com`). Desde la versión 1.6, axios no envía `X-XSRF-TOKEN` a otro origen si no se activa `withXSRFToken`.

### 3.2. Autenticación: `src/services/auth.js`

```js
import { api } from "./api";

export async function login(email, password) {
    await api.get("/sanctum/csrf-cookie");   // 1º: cookie XSRF-TOKEN
    const res = await api.post("/api/login", { email, password });
    return res.data;                          // usuario autenticado
}

export async function logout() {
    await api.post("/api/logout");
}

export async function currentUser() {
    try {
        const res = await api.get("/api/user");
        return res.data;
    } catch (e) {
        if (e.response?.status === 401) return null;   // no hay sesión
        throw e;
    }
}
```

### 3.3. Notas: `src/services/notes.js`

```js
import { api } from "./api";

export async function fetchNotes(page = 1) {
    const res = await api.get("/api/notes", { params: { page } });
    return res.data;   // { data, links, meta }
}

export async function createNote(note) {
    const res = await api.post("/api/notes", note);
    return res.data.data;
}

export async function deleteNote(id) {
    await api.delete(`/api/notes/${id}`);
}
```

Los servicios solo saben hablar con la API. Los componentes no conocen las URL: si cambia una ruta, solo se cambia aquí.

## 4. Componentes

### 4.1. `src/App.vue`

Al arrancar, pregunta a la API si ya hay sesión (`/api/user`). Así, si recargas la página, sigues autenticado.

```vue
<script setup>
import { ref, onMounted } from "vue";
import { currentUser, logout } from "./services/auth";
import LoginForm from "./components/LoginForm.vue";
import NotesPanel from "./components/NotesPanel.vue";

const user = ref(null);
const checking = ref(true);

onMounted(async () => {
    user.value = await currentUser();
    checking.value = false;
});

async function onLogout() {
    await logout();
    user.value = null;
}
</script>

<template>
    <main>
        <p v-if="checking">Comprobando la sesión…</p>
        <LoginForm v-else-if="!user" @logged-in="user = $event" />
        <template v-else>
            <header>
                <span>Hola, {{ user.name }}</span>
                <button @click="onLogout">Salir</button>
            </header>
            <NotesPanel @unauthenticated="user = null" />
        </template>
    </main>
</template>
```

### 4.2. `src/components/LoginForm.vue`

```vue
<script setup>
import { ref } from "vue";
import { login } from "../services/auth";

const emit = defineEmits(["logged-in"]);

const email = ref("");
const password = ref("");
const errors = ref({});
const sending = ref(false);

async function submit() {
    errors.value = {};
    sending.value = true;
    try {
        emit("logged-in", await login(email.value, password.value));
    } catch (e) {
        if (e.response?.status === 422) {
            errors.value = e.response.data.errors;   // { email: ["..."] }
        } else {
            errors.value = { email: ["No se ha podido conectar con el servidor."] };
        }
    } finally {
        sending.value = false;
    }
}
</script>

<template>
    <form @submit.prevent="submit">
        <h1>Acceso</h1>
        <label>Correo <input v-model="email" type="email" required /></label>
        <small v-if="errors.email">{{ errors.email[0] }}</small>
        <label>Contraseña <input v-model="password" type="password" required /></label>
        <button :disabled="sending">Entrar</button>
    </form>
</template>
```

### 4.3. `src/components/NotesPanel.vue`

```vue
<script setup>
import { ref, onMounted } from "vue";
import { fetchNotes, createNote, deleteNote } from "../services/notes";

const emit = defineEmits(["unauthenticated"]);

const notes = ref([]);
const meta = ref(null);
const form = ref({ title: "", description: "", date_at: "" });
const errors = ref({});

async function load(page = 1) {
    try {
        const res = await fetchNotes(page);
        notes.value = res.data;
        meta.value = res.meta;
    } catch (e) {
        handle(e);
    }
}

async function add() {
    errors.value = {};
    try {
        await createNote(form.value);
        form.value = { title: "", description: "", date_at: "" };
        await load();
    } catch (e) {
        handle(e);
    }
}

async function remove(id) {
    try {
        await deleteNote(id);
        await load(meta.value.current_page);
    } catch (e) {
        handle(e);
    }
}

function handle(e) {
    const status = e.response?.status;
    if (status === 401) emit("unauthenticated");          // sesión caducada
    else if (status === 422) errors.value = e.response.data.errors;
    else if (status === 403) alert("No tienes permiso para esta acción.");
    else alert("Error inesperado. Inténtalo de nuevo.");
}

onMounted(load);
</script>

<template>
    <section>
        <h2>Nueva nota</h2>
        <form @submit.prevent="add">
            <input v-model="form.title" placeholder="Título" />
            <small v-if="errors.title">{{ errors.title[0] }}</small>
            <textarea v-model="form.description" placeholder="Descripción"></textarea>
            <small v-if="errors.description">{{ errors.description[0] }}</small>
            <input v-model="form.date_at" type="date" />
            <small v-if="errors.date_at">{{ errors.date_at[0] }}</small>
            <button>Guardar</button>
        </form>

        <h2>Mis notas</h2>
        <ul>
            <li v-for="note in notes" :key="note.id">
                <strong>{{ note.titulo }}</strong> ({{ note.fecha }}, {{ note.estado }})
                <button @click="remove(note.id)">Borrar</button>
            </li>
        </ul>

        <nav v-if="meta && meta.last_page > 1">
            <button :disabled="meta.current_page === 1" @click="load(meta.current_page - 1)">Anterior</button>
            Página {{ meta.current_page }} de {{ meta.last_page }}
            <button :disabled="meta.current_page === meta.last_page" @click="load(meta.current_page + 1)">Siguiente</button>
        </nav>
    </section>
</template>
```

Los errores se tratan según el **código de estado**, que es el contrato de la API:

| Código | Qué hace la SPA |
| --- | --- |
| `401` | La sesión ha caducado: vuelve al login. |
| `403` | Avisa de que no hay permiso (apartado 11.3). |
| `422` | Muestra el error debajo de cada campo con `errors.campo[0]`. |
| Otros | Mensaje genérico, sin romper la aplicación. |

Los formularios de Vue tienen campos `required` para dar una respuesta rápida, pero **la validación que cuenta es la de Laravel**: el navegador se puede saltar y la API no.

## 5. Arrancar y probar

```bash
npm run dev
```

Abre `http://localhost:5173`, entra con el usuario de prueba (apartado 10.4) y comprueba:

1. Después del login aparece la lista de notas.
2. Si recargas la página, sigues dentro (la cookie de sesión se mantiene).
3. Si creas una nota sin título, aparece el error debajo del campo.
4. Después de **Salir**, `GET /api/user` devuelve `401` y vuelve a aparecer el login.

!!!tip "Mira las peticiones en el navegador"
    En las herramientas de desarrollo (F12), pestaña **Red**, puedes ver cada petición, su código de estado, las cookies `XSRF-TOKEN` y de sesión, y la cabecera `X-XSRF-TOKEN`. Es la mejor forma de entender el flujo y de encontrar errores.

## 6. ¿Y en producción?

El proxy de Vite solo existe en desarrollo. En producción, se genera la SPA con `npm run build` (carpeta `dist/`) y hay dos opciones habituales:

* **Mismo dominio**: el servidor web sirve la SPA en `https://midominio.com` y la API en `https://midominio.com/api`. No cambia nada.
* **Subdominios**: SPA en `https://app.midominio.com` y API en `https://api.midominio.com`. Hay que poner `SANCTUM_STATEFUL_DOMAINS=app.midominio.com`, `SESSION_DOMAIN=.midominio.com`, configurar **CORS** en Laravel (`php artisan config:publish cors`, con `supports_credentials => true` y el origen de la SPA en `allowed_origins`) y usar URL absolutas en axios (`baseURL`).
