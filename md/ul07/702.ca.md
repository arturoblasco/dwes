# <img src="../../img/laravel_azul.svg" width="40"> 11.2. Consum des de Vue

En este apartat creem la SPA en Vue que es connecta a l'API de l'apartat 11.1: login, llista de notes, creació amb errors de validació i logout.

!!!tenencuenta "Requisits"
    * L'API `testear` funcionant a `http://testear.test` (amb Sail, `http://localhost`).
    * **Node.js** 20 o superior (`node -v`).
    * Coneixements bàsics de Vue (components, `ref`, `v-if`, `v-for`, `v-model`), que es treballen en DWEC.

## 1. Crear el projecte Vue

Fora de la carpeta del projecte Laravel:

```bash
npm create vite@latest notas-vue -- --template vue
cd notas-vue
npm install
npm install axios
```

Estructura que utilitzarem:

```text
notas-vue/
├── vite.config.js          # proxy hacia Laravel
└── src/
    ├── main.js
    ├── App.vue             # muestra el login o las notas
    ├── services/
    │   ├── api.js          # instancia de axios
    │   ├── auth.js         # csrf, login, logout, usuario actual
    │   └── notes.js        # peticiones de notas
    └── components/
        ├── LoginForm.vue
        └── NotesPanel.vue
```

## 2. Proxy de desenvolupament

A `vite.config.js`:

```js
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

// Dirección de la API Laravel. Con Sail: "http://localhost"
const backend = "http://testear.test";

export default defineConfig({
    plugins: [vue()],
    server: {
        proxy: {
            "/api": { target: backend, changeOrigin: true },
            "/sanctum": { target: backend, changeOrigin: true },
        },
    },
});
```

Totes les peticions de la SPA a `/api/...` i `/sanctum/...` es reenvien a Laravel. Per al navegador, la SPA i l'API estan a `http://localhost:5173`: les galetes funcionen i no hi ha CORS (apartat 11.1).

!!!tenencuenta "Utilitza sempre rutes relatives"
    En el codi Vue escriu `/api/notes`, **mai** `http://testear.test/api/notes`. Si poses la URL completa, la petició se salta el proxy i tornen els problemes de galetes i CORS.

## 3. Serveis

### 3.1. Instància d'axios: `src/services/api.js`

```js
import axios from "axios";

export const api = axios.create({
    headers: { Accept: "application/json" },
    withCredentials: true,   // envía las cookies de sesión
    withXSRFToken: true,     // envía la cabecera X-XSRF-TOKEN
});
```

* `Accept: application/json`: Laravel respon sempre en JSON (apartat 10.1).
* `withCredentials` i `withXSRFToken`: amb el proxy, la SPA i l'API compartixen origen i axios ja enviaria la galeta i la capçalera CSRF. Les deixem activades perquè són **imprescindibles** si algun dia la SPA i l'API estan en orígens diferents (per exemple, `app.elmeudomini.com` i `api.elmeudomini.com`). Des de la versió 1.6, axios no envia `X-XSRF-TOKEN` a un altre origen si no s'activa `withXSRFToken`.

### 3.2. Autenticació: `src/services/auth.js`

```js
import { api } from "./api";

export async function login(email, password) {
    await api.get("/sanctum/csrf-cookie");   // 1º: cookie XSRF-TOKEN
    const res = await api.post("/api/login", { email, password });
    return res.data;                          // usuario autenticado
}

export async function logout() {
    await api.post("/api/logout");
}

export async function currentUser() {
    try {
        const res = await api.get("/api/user");
        return res.data;
    } catch (e) {
        if (e.response?.status === 401) return null;   // no hay sesión
        throw e;
    }
}
```

### 3.3. Notes: `src/services/notes.js`

```js
import { api } from "./api";

export async function fetchNotes(page = 1) {
    const res = await api.get("/api/notes", { params: { page } });
    return res.data;   // { data, links, meta }
}

export async function createNote(note) {
    const res = await api.post("/api/notes", note);
    return res.data.data;
}

export async function deleteNote(id) {
    await api.delete(`/api/notes/${id}`);
}
```

Els serveis només saben parlar amb l'API. Els components no coneixen les URL: si canvia una ruta, només es canvia ací.

## 4. Components

### 4.1. `src/App.vue`

En arrancar, pregunta a l'API si ja hi ha sessió (`/api/user`). Així, si recarregues la pàgina, continues autenticat.

```vue
<script setup>
import { ref, onMounted } from "vue";
import { currentUser, logout } from "./services/auth";
import LoginForm from "./components/LoginForm.vue";
import NotesPanel from "./components/NotesPanel.vue";

const user = ref(null);
const checking = ref(true);

onMounted(async () => {
    user.value = await currentUser();
    checking.value = false;
});

async function onLogout() {
    await logout();
    user.value = null;
}
</script>

<template>
    <main>
        <p v-if="checking">Comprobando la sesión…</p>
        <LoginForm v-else-if="!user" @logged-in="user = $event" />
        <template v-else>
            <header>
                <span>Hola, {{ user.name }}</span>
                <button @click="onLogout">Salir</button>
            </header>
            <NotesPanel @unauthenticated="user = null" />
        </template>
    </main>
</template>
```

### 4.2. `src/components/LoginForm.vue`

```vue
<script setup>
import { ref } from "vue";
import { login } from "../services/auth";

const emit = defineEmits(["logged-in"]);

const email = ref("");
const password = ref("");
const errors = ref({});
const sending = ref(false);

async function submit() {
    errors.value = {};
    sending.value = true;
    try {
        emit("logged-in", await login(email.value, password.value));
    } catch (e) {
        if (e.response?.status === 422) {
            errors.value = e.response.data.errors;   // { email: ["..."] }
        } else {
            errors.value = { email: ["No se ha podido conectar con el servidor."] };
        }
    } finally {
        sending.value = false;
    }
}
</script>

<template>
    <form @submit.prevent="submit">
        <h1>Acceso</h1>
        <label>Correo <input v-model="email" type="email" required /></label>
        <small v-if="errors.email">{{ errors.email[0] }}</small>
        <label>Contraseña <input v-model="password" type="password" required /></label>
        <button :disabled="sending">Entrar</button>
    </form>
</template>
```

### 4.3. `src/components/NotesPanel.vue`

```vue
<script setup>
import { ref, onMounted } from "vue";
import { fetchNotes, createNote, deleteNote } from "../services/notes";

const emit = defineEmits(["unauthenticated"]);

const notes = ref([]);
const meta = ref(null);
const form = ref({ title: "", description: "", date_at: "" });
const errors = ref({});

async function load(page = 1) {
    try {
        const res = await fetchNotes(page);
        notes.value = res.data;
        meta.value = res.meta;
    } catch (e) {
        handle(e);
    }
}

async function add() {
    errors.value = {};
    try {
        await createNote(form.value);
        form.value = { title: "", description: "", date_at: "" };
        await load();
    } catch (e) {
        handle(e);
    }
}

async function remove(id) {
    try {
        await deleteNote(id);
        await load(meta.value.current_page);
    } catch (e) {
        handle(e);
    }
}

function handle(e) {
    const status = e.response?.status;
    if (status === 401) emit("unauthenticated");          // sesión caducada
    else if (status === 422) errors.value = e.response.data.errors;
    else if (status === 403) alert("No tienes permiso para esta acción.");
    else alert("Error inesperado. Inténtalo de nuevo.");
}

onMounted(load);
</script>

<template>
    <section>
        <h2>Nueva nota</h2>
        <form @submit.prevent="add">
            <input v-model="form.title" placeholder="Título" />
            <small v-if="errors.title">{{ errors.title[0] }}</small>
            <textarea v-model="form.description" placeholder="Descripción"></textarea>
            <small v-if="errors.description">{{ errors.description[0] }}</small>
            <input v-model="form.date_at" type="date" />
            <small v-if="errors.date_at">{{ errors.date_at[0] }}</small>
            <button>Guardar</button>
        </form>

        <h2>Mis notas</h2>
        <ul>
            <li v-for="note in notes" :key="note.id">
                <strong>{{ note.titulo }}</strong> ({{ note.fecha }}, {{ note.estado }})
                <button @click="remove(note.id)">Borrar</button>
            </li>
        </ul>

        <nav v-if="meta && meta.last_page > 1">
            <button :disabled="meta.current_page === 1" @click="load(meta.current_page - 1)">Anterior</button>
            Página {{ meta.current_page }} de {{ meta.last_page }}
            <button :disabled="meta.current_page === meta.last_page" @click="load(meta.current_page + 1)">Siguiente</button>
        </nav>
    </section>
</template>
```

Els errors es tracten segons el **codi d'estat**, que és el contracte de l'API:

| Codi | Què fa la SPA |
| --- | --- |
| `401` | La sessió ha caducat: torna al login. |
| `403` | Avisa que no hi ha permís (apartat 11.3). |
| `422` | Mostra l'error davall de cada camp amb `errors.camp[0]`. |
| Altres | Missatge genèric, sense trencar l'aplicació. |

Els formularis de Vue tenen camps `required` per a donar una resposta ràpida, però **la validació que compta és la de Laravel**: el navegador es pot saltar i l'API no.

## 5. Arrancar i provar

```bash
npm run dev
```

Obri `http://localhost:5173`, entra amb l'usuari de prova (apartat 10.4) i comprova:

1. Després del login apareix la llista de notes.
2. Si recarregues la pàgina, continues dins (la galeta de sessió es manté).
3. Si crees una nota sense títol, apareix l'error davall del camp.
4. Després de **Salir**, `GET /api/user` torna `401` i torna a aparéixer el login.

!!!tip "Mira les peticions al navegador"
    A les ferramentes de desenvolupament (F12), pestanya **Xarxa**, pots veure cada petició, el seu codi d'estat, les galetes `XSRF-TOKEN` i de sessió, i la capçalera `X-XSRF-TOKEN`. És la millor manera d'entendre el flux i de trobar errors.

## 6. I en producció?

El proxy de Vite només existix en desenvolupament. En producció, es genera la SPA amb `npm run build` (carpeta `dist/`) i hi ha dues opcions habituals:

* **Mateix domini**: el servidor web servix la SPA a `https://elmeudomini.com` i l'API a `https://elmeudomini.com/api`. No canvia res.
* **Subdominis**: SPA a `https://app.elmeudomini.com` i API a `https://api.elmeudomini.com`. Cal posar `SANCTUM_STATEFUL_DOMAINS=app.elmeudomini.com` i `SESSION_DOMAIN=.elmeudomini.com`, configurar **CORS** en Laravel (`php artisan config:publish cors`, amb `supports_credentials => true` i l'origen de la SPA a `allowed_origins`) i utilitzar URL absolutes en axios (`baseURL`).
