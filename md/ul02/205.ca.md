# <img src="../../img/laravel_azul.svg" width="40"> 7.5. Del controlador a la vista

Per a crear aplicacions web dinàmiques, és fonamental integrar dades des del backend (controladors) cap a les vistes.

## 1. L'art de passar dades: del controlador a la vista

El controlador actua com a preparador d'informació: busca les dades necessàries, les processa, les estructura i les empaqueta perquè la vista les puga consumir de manera senzilla. Laravel proporciona múltiples mètodes per a fer esta transferència de dades, cada un amb els seus avantatges segons el context.

### 1.1. Mètode `view()` amb array associatiu

La manera més comuna de passar dades és usar un array associatiu com a segon paràmetre del mètode **`view()`**:

```php
// En app/Http/Controllers/ProductController.php
public function index(): View
{
    $products = $this->getAllProducts();
    $categories = $this->getCategories();
    $featuredProduct = $this->getFeaturedProduct();
    
    return view('products.index', [
        'products' => $products,
        'categories' => $categories,
        'featuredProduct' => $featuredProduct,
        'pageTitle' => 'Nuestros Productos'
    ]);
}
```

### 1.2. Mètode `with()` per a dades addicionals

També es pot usar el mètode **`with()`** per a afegir dades després de crear la vista:

```php
public function show(string $id): View
{
    $product = $this->findProduct($id);
    
    return view('products.show')
        ->with('product', $product)
        ->with('relatedProducts', $this->getRelatedProducts($product))
        ->with('reviews', $this->getReviews($product));
}
```

La diferència principal entre `with()` i passar un array és que `with()` és més encadenable i pot ser útil per a afegir dades condicionalment.

Per exemple, si només vols afegir certes dades si es complixen condicions específiques:

```php
$view = view('dashboard');
if ($user->isAdmin()) {
    $view->with('adminData', $this->getAdminData());
}
if ($user->hasNotifications()) {
    $view->with('notifications', $this->getNotifications($user));
}
return $view;
```

### 1.3. Mètode `compact()` per a variables locals

Quan les variables locals tenen el mateix nom que les claus de l'array, es pot usar **`compact()`**:

```php
public function create(): View
{
    $categories = $this->getCategories();
    $tags = $this->getTags();
    $inventory = $this->getInventory();
    
    return view('products.create', compact('categories', 'tags', 'inventory'));
}
```

Guia de selecció de mètodes

**Usa `view([...])`** quan:

* Passes múltiples variables amb noms clars.
* Vols veure totes les dades en un sol lloc.
* És la manera més comuna i llegible.

**Usa `with()`** quan:

* Afiges dades condicionalment.
* Encadenes múltiples crides.
* Vols un codi més fluid.

**Usa `compact()`** quan:

* Les variables locals tenen el mateix nom que les claus.
* Tens moltes variables amb noms descriptius.
* Preferixes un codi més compacte.

## 2. Redirecció

A vegades, després de processar una sol·licitud, cal redirigir l'usuari a una altra ruta o acció. Laravel ho facilita amb el mètode **`redirect()`**.

```php
public function store(Request $request)
{
    // Implementación para guardar un nuevo producto
    // ...
    // Redirigir al usuario a la página del producto recién creado
    return redirect()->route('products.show', ['id' => $product->id]);
}
```

### 2.1. Redirecció amb dades flash

Laravel permet passar dades temporals (flash data) durant una redirecció, que estaran disponibles en la sol·licitud següent. Això és útil per a missatges d'**èxit** o d'**error**.

```php
public function store(Request $request)
{
    // Implementación para guardar un nuevo producto
    // ...
    if ($error) {
        return redirect()->back()
                         ->withInput()
                         ->with('error', 'Hubo un problema al crear el producto.');
    }
    // Redirigir al usuario a la página del producto recién creado
    return redirect()->route('products.show', ['id' => $product->id])
                     ->with('success', 'Producto creado exitosamente!');
}
```

**Mostrar missatges flash en la vista:**

```html
<!-- resources/views/products/show.blade.php -->
@if(session('success'))
    <div class="alert alert-success">
        {{ session('success') }}
    </div>
@endif

@if(session('error'))
    <div class="alert alert-error">
        {{ session('error') }}
    </div>
@endif
```

## 3. Compartir dades globalment

A vegades necessites que certes dades estiguen disponibles en **totes les vistes** sense passar-les manualment en cada controlador.

**Cas d'ús:** Nom de l'aplicació, usuari autenticat, configuració global

```php
<?php
// app/Providers/AppServiceProvider.php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use Illuminate\Support\Facades\View;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Compartir datos con TODAS las vistas
        View::share('appName', 'Mi Tienda Online');
        View::share('appVersion', '1.0.0');
        View::share('currentYear', date('Y'));
    }
}
```

**Ús en qualsevol vista:**

```html
<!-- Ahora TODAS las vistas tienen acceso a estas variables -->
<footer>
    <p>&copy; {{ $currentYear }} {{ $appName }}</p>
    <small>Versión {{ $appVersion }}</small>
</footer>
```

**Responsabilitats clares**

**✅ En el controlador (lògica de negoci):**

* Obtindre dades de la base de dades
* Filtrar, ordenar, paginar
* Formatar dades complexes
* Preparar estructures de dades
* Càlculs matemàtics o estadístics

**✅ En la vista (presentació):**

* Iterar sobre col·leccions amb `@foreach`
* Mostrar/amagar amb `@if`
* Formatar text amb
* Aplicar estils CSS condicionals

**❌ Cal evitar en la vista:**

* Consultes a la base de dades
* Lògica de negoci complexa
* Càlculs pesats
* Modificar dades (només mostrar-les)
