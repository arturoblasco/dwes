# <img src="../../img/laravel_azul.svg" width="40"> 7.4. Layouts i herència en Blade
Els layouts són la columna vertebral de qualsevol aplicació web professional, ja que permeten mantindre una estructura visual coherent i fer canvis globals des d'un únic punt de control.

**Per què són essencials els layouts?** En aplicacions reals, totes les pàgines compartixen elements estructurals comuns: la barra de navegació, el peu de pàgina (footer), els enllaços a fulls d'estil CSS i scripts JavaScript, les metaetiquetes de SEO. Sense un sistema de layouts, canviar una cosa tan simple com el logotip de l'empresa requeriria editar manualment centenars de fitxers individuals.

Els layouts eliminen este malson, ja que centralitzen l'estructura comuna i permeten que cada pàgina se centre únicament en el seu contingut específic.


L'herència de plantilles és una de les característiques més potents de Blade. Permet crear un layout base que definix l'estructura comuna de totes les pàgines i, després, estendre eixe layout en pàgines específiques.



## 1. Directives d'herència

### 1.1. Directiva `@yield`

En el layout, definim seccions amb **`@yield`** que s'ompliran amb les seccions definides en les vistes filles usant **`@section`**:

```html
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <title>@yield('title', 'Mi Aplicación')</title> <!-- Título dinámico -->
</head>
<body>
    <header>
        <nav>
            <!-- Navegación común -->
        </nav>
    </header>

    <main>
        @yield('content') <!-- Contenido dinámico -->
    </main>

    <footer>
        <!-- Footer común -->
    </footer>
</body>
</html>
```

### 1.2. Directives `@extends` i `@section`

La directiva **`@extends`** especifica quin layout ha d'usar una vista. Ha de ser la primera línia del fitxer.

La directiva **`@section`** definix blocs de contingut que s'inserixen en el layout. Cada secció té un nom únic.

```html
<!-- resources/views/products/show.blade.php -->
@extends('layouts.app')

@section('title', 'Mi Título') <!-- Título dinámico -->

@section('content')            <!-- Contenido dinámico -->
    <h1>{{ $product->name }}</h1>
    <p>{{ $product->description }}</p>
    <p>Precio: {{ $product->price }}€</p>
@endsection
```


## 2. Directives avançades

### 2.1. Directiva `@parent`

La directiva **`@parent`** permet incloure el contingut de la secció pare en una secció que la sobreescriu:

```html
<!-- resources/views/products/show.blade.php -->
@extends('products.show')

@section('title') <!-- Título dinámico -->
    Mi Título 2
@endsection

@section('sidebar')
    @parent
    <p>Cantidad: {{ $product->quantity }}€</p>
@endsection
```

## 3. Stacks de Blade

### 3.1. Directiva `@push` i `@stack`
Els **stacks** (piles) són contenidors on múltiples vistes poden **acumular** contingut que després es renderitza en un punt específic del layout.


### 3.2 Exemple progressiu: vista de Producte

=== "Pas 1: Layout base amb stacks definits"
    ```html
    <!-- resources/views/layouts/app.blade.php -->
    <!DOCTYPE html>
    <html lang="es">
    <head>
        <meta charset="utf-8">
        <title>@yield('title', 'Mi Tienda')</title>
        
        <!-- CSS común cargado SIEMPRE -->
        <link rel="stylesheet" href="/css/app.css">
        
        <!-- Stack para CSS específico de cada página -->
        @stack('styles')
    </head>
    <body>
        <header>
            <nav><!-- Navegación común --></nav>
        </header>

        <main>
            @yield('content')
        </main>

        <footer><!-- Footer común --></footer>
        
        <!-- JavaScript común cargado SIEMPRE -->
        <script src="/js/app.js"></script>
        
        <!-- Stack para JavaScript específico de cada página -->
        @stack('scripts')
    </body>
    </html>
    ```
=== "Pas 2: Vista de producte que afig recursos específics"
    ```html
    <!-- resources/views/products/show.blade.php -->
    @extends('layouts.app')

    @section('title', $product->name)

    <!-- PUSH #1: Añade CSS específico de productos -->
    @push('styles')
        <link rel="stylesheet" href="/css/products.css">
    @endpush

    @section('content')
        <article class="product-card">
            <!-- Detalles del producto -->
        </article>
    @endsection

    <!-- PUSH #2: Añade JavaScript específico de productos -->
    @push('scripts')
        <!-- Librería externa para la galería de imágenes -->
        <script src="https://cdn.example.com/image-gallery.js"></script>
        
        <!-- Script específico de productos -->
        <script src="/js/products.js"></script>
    @endpush
    ```
=== "Pas 3: HTML final generat (el que veu el navegador)"
    ```html
    <!DOCTYPE html>
    <html lang="es">
    <head>
        <meta charset="utf-8">
        <title>Portátil HP 15</title>
        
        <!-- CSS común (del layout) -->
        <link rel="stylesheet" href="/css/app.css">
        
        <!-- ⬇️ TODO EL CONTENIDO DEL STACK 'styles' SE RENDERIZA AQUÍ ⬇️ -->
        <link rel="stylesheet" href="/css/products.css">
        <!-- ⬆️ FIN DEL STACK 'styles' ⬆️ -->
    </head>
    <body>
        <header>
            <nav><!-- Navegación común --></nav>
        </header>

        <main>
            <article class="product-card">
                <!-- Detalles del producto -->
            </article>
        </main>

        <footer><!-- Footer común --></footer>
        
        <!-- JavaScript común (del layout) -->
        <script src="/js/app.js"></script>
        
        <!-- ⬇️ TODO EL CONTENIDO DEL STACK 'scripts' SE RENDERIZA AQUÍ ⬇️ -->
        <script src="https://cdn.example.com/image-gallery.js"></script>
        <script src="/js/products.js"></script>
        <!-- ⬆️ FIN DEL STACK 'scripts' ⬆️ -->
    </body>
    </html>
    ```

**Avantatges dels stacks**

**💡1. Càrrega selectiva de recursos:**

* La pàgina de productes carrega `products.css` i la biblioteca de galeria.
* La pàgina de categories NO carrega eixos recursos (només els seus).
* Millor rendiment! No carregues codi innecessari.

**💡2. Múltiples push a la mateixa pila:**

* Pots fer `@push('scripts')` diverses vegades en la mateixa vista.
* Tots els push s'acumulen en orde.
* Útil quan tens codi HTML mesclat amb codi Blade.

**💡3. Sense acoblament:**

* El layout NO sap quins recursos necessita cada pàgina.
* Cada vista declara les seues pròpies dependències.
* És fàcil afegir/llevar funcionalitats sense tocar el layout.



## 4. Directives d'inclusió

### 4.1. Directiva `@include`

La directiva **`@include`** permet incloure una vista dins d'una altra. És útil per a components reutilitzables que solen ser fixos en totes les pàgines, com barres laterals, peus de pàgina, menús, etc.

```html
<!-- resources/views/layouts/app.blade.php -->
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <title>@yield('title', 'Mi Tienda')</title>
</head>
<body>
    @include('partials.header') <!-- Incluye el header común -->

    <main>
        @yield('content')
    </main>

    @include('partials.footer') <!-- Incluye el footer común -->
    
</body>
</html>
```

El contingut de `partials/header.blade.php` podria ser:

```html
<header>
    <h1>Mi Tienda</h1>
    <nav>
        <ul>
            <li><a href="/">Inicio</a></li>
            <li><a href="/products">Productos</a></li>
            <li><a href="/about">Acerca de</a></li>
            <li><a href="/contact">Contacto</a></li>
        </ul>
    </nav>
</header>
```

### 4.2. Passar variables als includes

Es poden passar variables a les vistes incloses:

```html
@include('partials.header', ['links' => $links])

<!-- O usando la sintaxis de array -->
@include('partials.header', $links)
```

### 4.3. Directiva `@includeIf`

Inclou una vista només si existix:

```html
<header>
    <h1>Mi Tienda</h1>
    @includeIf('partials.nav') <!-- Incluye la navegación común -->
    <!-- Si 'partials.nav' no existe, no hace nada -->
</header>
```

### 4.4. Directiva `@includeWhen`

Inclou una vista condicionalment:

```html
<header>
    <h1>Mi Tienda</h1>
    @includeWhen(count($links) > 0, 'partials.nav')
</header>
```
