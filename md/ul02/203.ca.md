# <img src="../../img/laravel_azul.svg" width="40"> 7.3. Vistes dinàmiques

En esta secció es descobrirà el motor de plantilles Blade, aprenent la seua sintaxi especial, les directives bàsiques de control de flux i com crear vistes dinàmiques professionals.

## 1. Què és Blade i per què usar-lo?

Blade és el motor de plantilles de Laravel que compila les vistes a PHP pur i les guarda en memòria cau per a obtindre un rendiment òptim. A diferència d'escriure HTML mesclat amb PHP, Blade proporciona una sintaxi més curta i segura.

### 1.1. Avantatges de Blade sobre PHP pur

**Sintaxi més neta:**

=== "❌ PHP pur"
    Verbós i propens a errors.
    ```php
    <?php if ($product->inventory->quantity > 0): ?>
        <button class="btn btn-primary">Añadir al Carrito</button>
    <?php else: ?>
        <button class="btn btn-secondary" disabled>Sin Stock</button>
    <?php endif; ?>
    ```
=== "✅ Blade"
    Net i llegible.
    ```php
    <?php
    @if($product->inventory->quantity > 0)
        <button class="btn btn-primary">Añadir al Carrito</button>
    @else
        <button class="btn btn-secondary" disabled>Sin Stock</button>
    @endif
    ```

**Seguretat automàtica:**

Escapar significa convertir caràcters especials en una representació segura per a evitar que siguen interpretats com a codi executable. És una tècnica fonamental de seguretat web.


```blade
{{ $product->description }}
```

**Per què cal escapar?**

Imagina que un usuari maliciós introduïx la cadena següent com a "nom" en un formulari:

```html
<script>alert('Sitio hackeado!');</script>
```

Si no escapes esta entrada i la mostres directament:

```php
// ❌ SIN escapar - PELIGROSO
<?php echo $user_name; ?>

// Resultado: 
// <script>alert('Sitio hackeado!');</script>
// El navegador ejecutará el JavaScript malicioso
```

!!!tenencuenta "Què fa *escapar*"

    Escapar consistix a convertir caràcters especials en entitats que el navegador no executa. Per exemple:

    - `<`  → `&lt;`
    - `>`  → `&gt;`
    - `"`  → `&quot;`
    - `'`  → `&#039;`

    Així el navegador mostra el contingut com a text i no com a HTML ni JavaScript.


**Herència de plantilles:**

=== "❌ PHP pur (repetitiu)"
    ```php
    header.php
    footer.php
    // product.php (incluye header y footer)
    ```
=== "✅ Blade (herència elegant)"
    ```php
    @extends('layouts.app')
    @section('content')
        <!-- contenido específico del producto -->
    @endsection
    ```

## 2. Sintaxi bàsica de Blade

Blade utilitza una sintaxi especial que comença amb **`@`** per a les seues directives. Esta sintaxi es compila a PHP pur, però és molt més llegible i segura.

### 2.1. Renderització de variables

La manera més bàsica de mostrar dades en Blade és usar les claus dobles:

```text
{{ }}
```

!!!examplelaravel "Exemple"
    ```html
    <!-- Mostrar una variable simple -->
    <h1>{{ $product->name }}</h1>

    <!-- Mostrar propiedades de objetos -->
    <p>Precio: {{ $product->price }}€</p>

    <!-- Mostrar elementos de arrays -->
    <p>Categoría: {{ $product['category'] }}</p>
    ```

### 2.2. Renderització sense escapar

Per a mostrar HTML sense escapar (cal usar-ho amb precaució), utilitza `{!! !!}`:

```html
<!-- Escapado automático (seguro) -->
<p>{{ $product->description }}</p>
<!-- Si $product->description contiene <script>alert('hack')</script> -->
<!-- Se mostrará como texto: &lt;script&gt;alert('hack')&lt;/script&gt; -->

<!-- Sin escapar (peligroso si no confías en el contenido) -->
<div>{!! $product->html_description !!}</div>
```


## 3. Directives de control de flux

Blade proporciona directives elegants per a controlar el flux de l'aplicació en les vistes.

### 3.1. Condicionals

A més de les directives condicionals més comunes com **`@if`**, **`@elseif`** i **`@else`**, Blade oferix altres directives útils per a controlar el flux en les vistes:

* **`@isset`**: Permet comprovar si una variable està definida i no és `null`. És útil per a evitar errors quan no estàs segur de si una variable existix.
* **`@empty`**: Verifica si una variable està buida. És pràctic per a mostrar missatges alternatius quan, per exemple, una col·lecció no té elements.

Estes directives fan que el codi Blade siga més expressiu i fàcil de llegir, i permeten gestionar casos especials de manera senzilla i elegant.

```html
<!-- @if, @elseif, @else -->
@if($user->isAdmin())
    <div class="admin-panel">Panel de administración</div>
@elseif($user->isModerator())
    <div class="moderator-panel">Panel de moderador</div>
@else
    <div class="user-panel">Panel de usuario</div>
@endif


<!-- @isset (verificar si existe) -->
@isset($product->brand)
    <p>Marca: {{ $product->brand }}</p>
@endisset


<!-- @empty (verificar si está vacío) -->
@empty($products)
    <p>No hay productos disponibles</p>
@endempty
```

### 3.2. Bucles

A continuació es mostren exemples de les directives de bucle en Blade.

 Les més habituals són **`@foreach`** i **`@for`**, però Blade també oferix altres directives molt útils:

* **`@forelse`**: És semblant a `@foreach`, però permet definir un bloc **`@empty`** que s'executa si la col·lecció està buida. És molt útil per a mostrar un missatge quan no hi ha elements per recórrer.
* **`@while`**: Permet executar un bloc de codi mentre una condició siga certa, igual que en PHP pur, però amb la sintaxi de Blade.

!!!examplelaravel "Exemples"
    === "@foreach"
        ```blade
        @foreach($products as $product)
            <div class="product">
                <h3>{{ $product->name }}</h3>
                <p>{{ $product->description }}</p>
            </div>
        @endforeach
        ```
    === "@forelse"
        ```blade
        @forelse($products as $product)
            <div class="product">
                <h3>{{ $product->name }}</h3>
            </div>
        @empty
            <p>No hay productos para mostrar</p>
        @endforelse
        ```
    === "@for"
        ```blade
        @for($i = 0; $i < 10; $i++)
            <p>Iteración {{ $i }}</p>
        @endfor
        ```
    === "@while"
        ```blade
        @while($condition)
            <p>Ejecutando mientras la condición sea verdadera</p>
        @endwhile
        ```

#### 3.2.1. La variable `$loop` en bucles

Dins de qualsevol bucle `@foreach`, Blade proporciona automàticament una variable **`$loop`** amb informació útil sobre la iteració actual:

```html
@foreach($products as $product)
    <div class="product {{ $loop->first ? 'featured' : '' }}">
        <h3>{{ $product->name }}</h3>
        <p>Producto {{ $loop->iteration }} de {{ $loop->count }}</p>
        
        @if($loop->last)
            <p>Este es el último producto</p>
        @endif
    </div>
@endforeach
```

**Propietats de `$loop`:**

* `$loop->first`: `true` si és la primera iteració.
* `$loop->last`: `true` si és l'última iteració.
* `$loop->iteration`: número de la iteració actual (comença en 1).
* `$loop->index`: índex actual (comença en 0).
* `$loop->count`: nombre total d'elements.
* `$loop->remaining`: elements restants.
* `$loop->depth`: profunditat del bucle niat.

???examplelaravel "Exemple per a `$loop`"
    ```blade
    <h2>Ejemplo de propiedades de $loop</h2>

    @php
        $frutas = ['Manzana', 'Naranja', 'Plátano', 'Pera'];
    @endphp

    <ul>
    @foreach ($frutas as $fruta)
        <li>
            🍎 <strong>{{ $fruta }}</strong><br>

            <small>
                Iteración: {{ $loop->iteration }} <br>
                Índice: {{ $loop->index }} <br>
                Total: {{ $loop->count }} <br>
                Restantes: {{ $loop->remaining }} <br>
                Primera iteración: {{ $loop->first ? 'Sí' : 'No' }} <br>
                Última iteración: {{ $loop->last ? 'Sí' : 'No' }} <br>
                Profundidad del bucle: {{ $loop->depth }}
            </small>
        </li>

        @if ($loop->first)
            <ul>
                @foreach (['Roja', 'Verde'] as $color)
                    <li>
                        Color: {{ $color }}  
                        <small>(profundidad: {{ $loop->depth }})</small>
                    </li>
                @endforeach
            </ul>
        @endif

    @endforeach
    </ul>
    ```

## 4. Directives d'autenticació

Blade inclou directives especials per a gestionar l'autenticació d'usuaris:

```html
<!-- @auth / @endauth -->
<!--Se mostrará si el usuario está autenticado (inicio de sesión) -->
@auth
    <p>Bienvenido, {{ auth()->user()->name }}</p>
    <a href="/dashboard">Ir al panel</a>
@endauth

<!-- @guest / @endguest -->
<!--Solo se muestra a usuarios no autenticados (visitantes). -->
@guest
    <p>Por favor, inicia sesión para continuar</p>
    <a href="/login">Iniciar sesión</a>
@endguest

<!-- Verificar usuario específico -->
@auth('admin')
    <div class="admin-panel">Panel de administración</div>
@endauth
```

## 5. Directives de formularis

Blade proporciona directives útils per a treballar amb formularis:

- **`@csrf`** inserix automàticament un token secret dins del formulari.
  Evita atacs del tipus CSRF (Cross-Site Request Forgery), que consistixen a enganyar un usuari autenticat perquè envie peticions malicioses al teu lloc.
```html
<!-- @csrf (protección CSRF) -->
<form method="POST" action="/products">
    @csrf
    <input type="text" name="name">
    <button type="submit">Crear producto</button>
</form>
```

- **`@method('PUT | PATCH | DELETE')`** Els navegadors només permeten enviar formularis amb GET o POST. Però Laravel (i l'estàndard HTTP) admet més mètodes: PUT, PATCH, DELETE.
```html
<!-- @method (para PUT, PATCH, DELETE) -->
<form method="POST" action="/products/1">
    @csrf
    @method('PUT')
    <input type="text" name="name" value="{{ $product->name }}">
    <button type="submit">Actualizar producto</button>
</form>
```

- **`@error` / `@enderror`** Quan valides dades en un controlador i hi ha errors, Laravel redirigix de nou al formulari amb missatges d'error. La directiva @error('camp') comprova si hi ha un error per a eixe camp i, si n'hi ha, mostra el seu missatge.
```html
<!-- @error / @enderror -->
<input type="text" name="title" value="{{ old('title') }}">
@error('title')
    <div class="error">{{ $message }}</div>
@enderror
```

!!!tip "&nbsp;"
    Les directives d'autenticació i de formularis es veuran amb més profunditat en la ***sessió 4***, quan s'implementen de manera pràctica.
