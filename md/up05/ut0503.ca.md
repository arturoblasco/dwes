# <img src="../../img/php_azul.svg" width="40"> 5.3. Estructura de BD

Fent una ullada al mòdul de primer curs *Bases de Dades* sabem que una base de dades té molts camps amb els seus noms i valors; però, a més, sabem que la base de dades ha de tindre un nom. Per tant, tindríem l'estructura següent per a una base de dades:

```bash
NombreBaseDeDatos
    |__Tabla-#1
    |         |__DatosTabla-#1
    |
    |__Tabla-#2
    |         |__DatosTabla-#2
    |    
    |__Tabla-#3
    |         |__DatosTabla-#3
    [...]
```
!!!examplephp  "Exemple real"
    ```bash
    Ryanair
        |__pasajero
        |     |__id[*]
        |     |__nombre
        |     |__apellidos
        |     |__edad
        |     |__id_vuelo[^]
        |
        |__vuelo
        |     |__id[*]
        |     |__n_plazas
        |     |__disponible
        |     |__id_pais[^]
        |
        |__pais
              |__id[*]
              |__nombre
              
              
    [*] Clave primaria    [^] Clave Foránea
    ```
