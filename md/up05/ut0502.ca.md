# <img src="../../img/php_azul.svg" width="40"> 5.2. Instal·lació

Podem instal·lar dues opcions:

&nbsp;&nbsp;&nbsp; a) **XAMPP**: simplement descarregaríem el programa i l'activaríem. Per a descarregar XAMPP [**prem ací**](https://www.apachefriends.org/es/download.html){:target="_blank"}.

&nbsp;&nbsp;&nbsp; b) **Docker**: utilitzant el programari de contenidors, descarregarem la **imatge docker d'esta unitat didàctica del curs** i executarem:

```bash
docker-compose up -d
```

Si tot ha anat bé i el contenidor està en marxa, podrem visitar la pàgina de *phpMyAdmin* de la manera següent:

```bash
http://localhost:8000
```

Per a accedir hem d'utilitzar les credencials següents, que vénen configurades en el fitxer `docker-compose.yml`:

```sh
usuario: root
contraseña: 1234
```

!!!note "Recorda"
    Podem utilitzar també el docker *Portainer* per a gestionar (llançar, parar, accedir a) els contenidors generats en la imatge anterior.
