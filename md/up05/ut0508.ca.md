<div style="text-align: center;"><figure><img src="../../img/ut05/img08_06-login-password.gif"  style="zoom: 100%;" /><figcaption class="figure-caption-small">🖼️ Figura 5.6: Exemple d'introducció d'usuari i contrasenya</figcaption></figure></div>


Per a gestionar un sistema complet de login i password amb contrasenyes xifrades, necessitem un mètode que xifre eixes cadenes que l'usuari introduïx com a contrasenya, tant en el formulari de registre com en el del login, ja que, en codificar una contrasenya, després hem de descodificar-la per a comprovar que les dues contrasenyes (la que introduïx l'usuari en el login i la que tenim en la base de dades) coincidixen.

Necessitem, doncs:

1r ) `password_hash()` per a emmagatzemar la contrasenya en la base de dades a l'hora de fer l'INSERT.

- `PASSWORD_DEFAULT`: emmagatzemem la contrasenya usant el mètode de xifratge *bcrypt*.
- `PASSWORD_BCRYPT`: emmagatzemem la contrasenya usant l'algorisme CRYPT_BLOWFISH compatible amb crypt().

2n ) `password_verify()` per a verificar l'usuari i la contrasenya.

Exemple:

```html
<form action="loginCrear.php" method="post">
    <label for="usuario">usuario: </label>
    <input type="text" name="usuario">
    
    <label for="password">password: </label>
    <input type="password" name="password"> 

    <input type="submit" name="enviar" value="enviar">
</form>
```

```php
<?php
  // loginCrear.php
  include "config/database.inc.php";

  $conexion = null;
  try{
    $conexion = new PDO($dsn, $usuario, $contrasenya);
    $conexion -> setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    $usu = $_POST["usuario"];
    $pas = $_POST["password"];    
    $fechaActual = date("Y-m-d H:i:s"); 
    $cre = $fechaActual; 
    $acc = $fechaActual;  

    // Encriptar la contraseña
    $pasE= password_hash($pas, PASSWORD_DEFAULT);

    $sql = "INSERT INTO users (username, password, creacion, actualizacion) 
                                      VALUES (:usu, :pas, :cre, :acc)";

    $sentencia = $conexion -> prepare($sql);
    $sentencia -> bindParam (':usu', $usu);  
    $sentencia -> bindParam (':pas', $pasE);  
    $sentencia -> bindParam (':cre', $cre);  
    $sentencia -> bindParam (':acc', $acc);  
    $isOk = $sentencia -> execute();
    //$idGenerado = $conexion -> lastInsertId();

  } catch (PDOException $e) {
    echo $e -> getMessage();
  }

  $conexion = null;  
```

Ara que tenim l'usuari codificat i guardat en la base de dades, el recuperarem per a poder iniciar-li la sessió correctament.

```php
<?php
  // Recuperar usuario y password en BD
  include "config/database.inc.php";
  $conexion = null;
  try{
    $conexion = new PDO(DSN, USUARIO, PASSWORD);
    $conexion -> setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    $usu = $_POST["usuario"] ?? "";
    $sql = "select * from usuarios where usuario = :usu";

    $sentencia = $conexion -> prepare($sql);
    $sentencia -> bindParam (':usu', $usu);  
    $sentencia -> execute();

    $usuario = $sentencia -> fetch();

    if($usuario && password_verify($_POST['password'], $usuario['password'])) {
        echo "OK!";
    } else {
        echo "Usuario y/o contraseña no son correctos.";
    }
  } catch (PDOException $e){
    echo $e->getMessage();
 }
 $conexion = null;
```
