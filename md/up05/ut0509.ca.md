# <img src="../../img/php_azul.svg" width="40"> 5.9. Accés a fitxers

Gràcies a la funció `fopen()`, des de PHP podem obrir fitxers que es troben en el nostre servidor o en una URL.

A esta funció cal passar-li 2 paràmetres: el **nom del fitxer** que volem obrir **i** el **mode** en què s'obrirà:

```php
$fp = fopen("miarchivo.txt", "r");
```

Moltes vegades no podem obrir el fitxer perquè no es troba o no hi tenim accés; per això és recomanable comprovar que ho podem fer:

```php
if (!$fp = fopen("miarchivo.txt", "r")){
    echo "No se ha podido abrir el archivo";
}
```

## 1. Modes d'obertura de fitxers

- `r` : Mode lectura. Punter al principi del fitxer.
- `r+` : Obertura per a lectura i escriptura. Punter al principi del fitxer.
- `w` : Obertura per a escriptura. Punter al principi del fitxer i el sobreescriu. Si no existix, s'intenta crear.
- `w+` : Obertura per a lectura i escriptura. Punter al principi del fitxer i el sobreescriu. Si no existix, s'intenta crear.
- `a` : Obertura per a escriptura. Punter al final del fitxer. Si no existix, s'intenta crear.
- `a+` : Obertura per a lectura i escriptura. Punter al final del fitxer. Si no existix, s'intenta crear.
- `x` : Creació i obertura només per a escriptura. Punter al principi del fitxer. Si el fitxer ja existix, donarà l'error E_WARNING. Si no existix, s'intenta crear.
- `x+` : Creació i obertura per a lectura i escriptura. Mateix comportament que x.
- `c` : Obertura per a escriptura. Si no existix, es crea. Si existix, no se sobreescriu ni dona cap error. Punter al principi del fitxer.
- `c+` : Obertura per a lectura i escriptura. Mateix comportament que C.
- `b` : Quan es treballa amb fitxers binaris com jpg, pdf, png i altres. Se sol col·locar al final del mode, és a dir, rb, r+b, x+b, wb...

## 2. Operacions amb fitxers

Per a poder **llegir** un fitxer necessitem usar la funció `fread()` de PHP:

```php
<?php
    // ▒▒ Abriendo un archivo y leyendo su contenido ▒▒
    $file = "miarchivo.txt";
    $fp = fopen($file, "r");

    // $contents guardará el contenido
    // filesize() nos devuelve el tamaño del archivo en cuestión
    $contents = fread($fp, filesize($file));
    print $contents;

    // Cerramos la conexión con el archivo
    fclose($fp)
?>
```

Si el que volem és **escriure** en un fitxer, haurem de fer ús de la funció`fwrite()` :

```php
<?php
    // ▒▒ Escribiendo en un archivo ▒▒
    $file = "miarchivo.txt";
    $texto = "Hola qué tal";

    $fp = fopen($file, "w");

    fwrite($fp, $texto);
    fclose($fp);
?>
```

## 3. Informació d'un fitxer

Amb PHP i el seu mètode `stat()` podem obtindre informació sobre els fitxers que li indiquem. Este mètode retorna fins a un total de 12 elements amb informació sobre el nostre fitxer.

```processing
0   dev         número de dispositivo
1   ino         número de i-nodo
2   mode        modo de protección del i-nodo
3   nlink       número de enlaces
4   uid         ID de usuario del propietario
5   gid         ID de grupo del propietario
6   rdev        tipo de dispositivo, si es un dispositivo i-nodo
7   size        tamaño en bytes
8   atime       momento del último acceso (tiempo Unix)
9   mtime       momento de la última modificación (tiempo Unix)
10  ctime       momento de la última modificación del i-nodo (tiempo Unix)
11  blksize     tamaño del bloque E/S del sistema de ficheros
12  blocks      número de bloques de 512 bytes asignados
```

Uns quants exemples...

```php
<?php
  // ▒▒ Información del archivo ▒▒

  $file = "miarchivo.txt";
  $texto = "Todos somos muy ignorantes, lo que ocurre es que no todos ignoramos las mismas cosas.";

  $fp = fopen($file, "w");
  fwrite($fp, $texto);

  $datos = stat($file);
  
  echo $datos[3] . "<br>"; // Número de enlaces, 1
  echo $datos[7] . "<br>"; // Tamaño en bytes, 85
  echo $datos[8] . "<br>"; // Momento de último acceso, 1444138104
  echo $datos[9] . "<br>"; // Momento de última modificación, 1444138251
?>
```

Fes una ullada a [**les funcions de directoris**](https://www.php.net/manual/es/book.dir.php){:target="_blank"} que té PHP, és molt interessant.

## 4. Fitxers PDF

<img src="../../img/ut05/img09_05-pdf.png" alt="logotip PDF" style="zoom:20%; float:left;" />Amb PHP podem gestionar tota mena de fitxers, com ja hem vist, però *què passa si volem generar fitxers PDF amb dades tretes d'una base de dades*?

Gràcies a una classe escrita en PHP, podem generar fitxers PDF sense necessitat d'instal·lar llibreries addicionals en el nostre servidor.

Per a això, com que tenim *composer* dins del nostre projecte en XAMPP o dins de la nostra imatge de Docker, usarem **composer** per a instal·lar esta dependència.

!!!inst "Instal·lar una biblioteca des de Composer"
    === "<div style="text-align:center;"><img src="../../img/linux.png" alt="linux" width=40 height=40 /></div>"
    	1r **inicia Composer**<br/>
    	Executa el comandament per a inicialitzar un fitxer `composer.json` en el teu projecte.
        ```sh
		/opt/lampp/bin/php /usr/local/bin/composer init
		```
		2n **instal·la una biblioteca per a PDF**, com ara **FPDF** (n'hi ha d'altres, com Dompdf):
		```sh
		/opt/lampp/bin/php /usr/local/bin/composer require setasign/fpdf
		```
		3r **Verifica la instal·lació**<br/>
		Composer descarregarà la biblioteca en la carpeta `vendor/` i actualitzarà el fitxer `composer.json` amb les dependències.
		Confirma que s'han creat la carpeta `vendor/` i el fitxer `composer.lock`.

	=== "<div style="text-align:center;"><img src="../../img/windows.png" alt="windows" width=40 height=40 /></div>"
		1r **inicia Composer**<br/>
		Executa el comandament per a inicialitzar un fitxer `composer.json` en el teu projecte.		
		```sh
		php C:\xampp\php\composer.phar init
		```
		O, si Composer està configurat globalment en el teu sistema, pots executar simplement:
		```sh
		composer init
		```
		2n **Instal·la `setasign/fpdf`** Si Composer està configurat globalment, executa:
		```sh
		composer require setasign/fpdf
		```
		Si estàs usant `composer.phar` en el directori de PHP de XAMPP, utilitza:
		```sh
		php C:\xampp\php\composer.phar require setasign/fpdf
		```
		3r **Verifica la instal·lació**<br/>
		Composer descarregarà la biblioteca en la carpeta `vendor/` i actualitzarà el fitxer `composer.json` amb les dependències.
		Confirma que s'han creat la carpeta `vendor/` i el fitxer `composer.lock`.


!!!examplephp "Exemple de `Hola Mundo` convertit a PDF"
    ```php
    <?php
    require_once __DIR__ . '/vendor/autoload.php';

    // Instanciamos la clase
    // P = Portrait | mm = unidades en milímetros | A4 = formato
    $pdf = new FPDF('P','mm','A4');
    
    // Añadimos una página
    $pdf->AddPage();
    
    // Establecemos la fuente y el tamaño de letra
    $pdf->SetFont('Arial', 'B', 18);
    
    // Imprimimos una celda con el texto que nosotros queramos
    $pdf->Cell(60,20,'Hola clase DWES!');
    
    // Terminamos el PDF
    $pdf->Output();
    ?>
    ```

Hi ha molts exemples i tutorials, així com documentació de la classe FPDF, en la pàgina oficial. 

Visita [**la secció de tutorials i el manual**](http://www.fpdf.org/){:target="_blank"} per a traure més partit a esta classe.

!!!examplephp "Un altre exemple d'FPDF"
    ```php
    <?php
    require_once __DIR__ . '/vendor/autoload.php';

    class MiPdf extends FPDF {
       // Cabecera
       function Header() {
          // Añadimos un logotipo
          $this->Image('logo.png',10,7,22);
          // establecemos la fuente y el tamaño
          $this->SetFont('Arial','B',18);
          // Movemos el contenido un poco a la derecha
          $this->Cell(60);
          // Pintamos la celda
          $this->Cell(80,10,'IES Mestre Ramon Esteve',1,3,'C');
          // Pasamos a la siguiente línea
          $this->Ln(15);
       }
    
       // Pie de página
       function Footer() {
          // Nos posicionamos a 1.5 cm  desde abajo del todo de la página
          $this->SetY(-15);
          // Arial italic 8
          $this->SetFont('Arial','I',8);
          // Número de página
          $this->Cell(0,10,'pagina ' . $this->PageNo() . ' | {nb}',0,0,'C');
       }
    }
    
    // Instanciamos la clase
    $pdf = new MiPdf();
    
    // Definimos un alias para la numeración de páginas
    $pdf->AliasNbPages();
    
    $pdf->AddPage();
    $pdf->SetFont('Times','',14);
    
    for($i = 1; $i <= 30; $i++){
        $pdf->Cell(0, 10, 'Numero de linea: ' . $i, 0, 1);
    }
    //$pdf->Output();
    $pdf->Output('documento.pdf', 'I');
    
    ?>
    ```
