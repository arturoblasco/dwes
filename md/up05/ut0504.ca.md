# <img src="../../img/php_azul.svg" width="40"> 5.4. SQL


Utilitzarem el llenguatge de consulta estructurada (*Structured Query Language*) SQL per a fer les consultes a les nostres bases de dades i per a mostrar el contingut en les diferents interfícies web que creem al llarg de la unitat. Si vols saber-ne més detalls, visita [**Wiki SQL**](https://es.wikipedia.org/wiki/SQL){:target="_blank"}.

Exemple d'una sentència SQL en què seleccionem totes les files i columnes de la nostra taula anomenada `pais`:

```sql
SELECT * FROM pais
```

Estes sentències es poden invocar des de la consola de comandaments mitjançant l'intèrpret `mysql` (instal·lat prèviament en el sistema) o a través de l'eina `phpMyAdmin`.

Les sentències SQL també les podem usar dins del nostre codi PHP, de manera que, quan es carregue la nostra interfície web, llance una sentència SQL per a mostrar les dades que vulguem.

```php
<?php
	// Listado de clientes, ordenados por DNI de manera ASCendente
	$clientesOrdenadosPorDNI = "SELECT * FROM `pasajero` ORDER BY `dni` ASC";
?>
```
