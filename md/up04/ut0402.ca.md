# <img src="../../img/php_azul.svg" width="40"> 4.2. Variable de servidor

PHP emmagatzema la informació del servidor i de les peticions HTTP en sis arrays globals:

- `$_ENV`: informació sobre les variables d'entorn.
- `$_GET`: paràmetres enviats en la petició GET.
- `$_POST`: paràmetres enviats en l'enviament POST.
- `$_COOKIE`: conté les cookies de la petició, les claus de l'array són els noms de les cookies.
- `$_SERVER`: informació sobre el servidor.
- `$_FILES`: informació sobre els fitxers carregats via upload.

## 1. $_SERVER

Si ens centrem en l'array `$_SERVER` podem consultar les propietats següents:

- `PHP_SELF`: nom de l'script executat, relatiu al document root (p. ex. `/tienda/carrito.php`).
- `SERVER_SOFTWARE`: (p. ex. `Apache`).
- `SERVER_NAME`: domini, àlies DNS (p. ex. `www.mitienda.es`).
- `REQUEST_METHOD`: GET.
- `REQUEST_URI`: URI, sense el domini.
- `QUERY_STRING`: tot el que va després de `?` en la URL (p. ex.: `nombre=Cambria&stock=14`).

Altres propietats relacionades:

- **`PATH_INFO`**: ruta extra després de la petició (p. ex. si la URL és `http://www.php.com/php/pathInfo.php/algo/cosa?foo=bar`, aleshores  `$_SERVER['PATH_INFO']`  serà `/algo/cosa`).
- **`REMOTE_HOST`**: hostname que va fer la petició.
- **`REMOTE_ADDR`**: IP del client.
- **`AUTH_TYPE`**: tipus d'autenticació (p. ex. `Basic`).
- **`REMOTE_USER`**: nom de l'usuari autenticat.

Apache crea una clau per a cada capçalera HTTP, en majúscules i substituint els guions per guions baixos:

- **`HTTP_USER_AGENT`**: agent (navegador).
- **`HTTP_REFERER`**: pàgina des de la qual es va fer la petició.

```php
<?php
    echo $_SERVER["HTTP_USER_AGENT"]."<br>"; // Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/87.0.4280.88 Safari/537.36
```
