# <img src="../../img/php_azul.svg" width="40"> 4.5. Gestió de l'estat

HTTP és un protocol *stateless* (sense estat). Per això, se simula l'estat mitjançant l'ús de *cookies*, *tokens* o *sessions*. L'estat és necessari per a processos com ara el carret de la compra, operacions associades a un usuari, etc. El mecanisme de PHP per a gestionar la sessió empra *cookies* de manera interna. Les *cookies* s'emmagatzemen en el navegador, i la *sessió* en el servidor web.

## 1. Cookies

Les *cookies* s'emmagatzemen en l'array global **`$_COOKIE`**. El que col·loquem dins d'este *array* es guardarà en el client

> **Acceptar cookies**
> 
> Cal tindre present que el client pot no voler emmagatzemar-les.
> <div style="text-align: center;"><figure><img src="../../img/ut04/cookies.png" alt="img03_cookies1" style="zoom:90%;border: 2px solid #83abd4;" /></figure><figcaption class="figure-caption-small">🖼️ Figura 4.4: Tira còmica que representa l'obligatorietat d'acceptar les cookies en algunes pàgines web</figcaption></figure></div>


La majoria de navegadors moderns tenen una limitació de 180-200 *cookies* per domini (amb una grandària màxima de 4KB per cookie) i de 4000-8000 en total en el navegador.

En PHP, per a crear una cookie s'utilitza la funció **`setcookie`**:

```php
<?php
  setcookie(nombre [, valor [, expira [, ruta [, dominio [, seguro [, httponly ]]]]]]);
  setcookie(nombre [, valor = "" [, opciones = [] ]] )
?>
```

Cal destacar que el nom no pot contindre espais ni el caràcter **`;`**.

???examplephp "Exemple"
    Per exemple, mitjançant *cookies* podem comprovar la quantitat de visites diferents que fa un usuari:
    ```php
    <?php
      $accesosPagina = 0;
      if (isset($_COOKIE['accesos'])) { 
         $accesosPagina = $_COOKIE['accesos']; // recuperamos una cookie
         setcookie('accesos', ++$accesosPagina); // le asignamos un valor
      }
    ?>
    ```

!!! note "Inspeccionar les cookies"
	Si volem veure què contenen les *cookies* que tenim emmagatzemades en el navegador, se'n pot comprovar el valor en **Dev Tools** > **Storage**

Per a esborrar una cookie es pot fer que expire en el passat:

```php
<?php
	setcookie(nombre, "", 1) // pasado
```

O que caduque dins d'un període de temps determinat:

```php
<?php
	setcookie(nombre, valor, time() + 3600) // Caducan dentro de una hora
```

## 2. Sessió

La *sessió* afig la gestió de l'estat a HTTP, i en este cas emmagatzema la informació en el servidor. Cada visitant té un *ID de sessió* únic, que per defecte s'emmagatzema en una cookie anomenada `PHPSESSID`. Si el client no té les *cookies* actives, l'*ID* es propaga en cada URL dins del mateix domini. Cada sessió té associat un magatzem de dades mitjançant l'array global `$_SESSION`, en el qual podem emmagatzemar i recuperar informació.

La sessió comença en executar un script PHP. Es genera un nou *ID* i es carreguen les dades del magatzem:

<div style="text-align: center;"><figure><img src="../../img/ut04/img02comunicacionSesion.png" alt="img02comunicacionSesion" style="zoom:45%;border: 2px solid #83abd4;" /></figure><figcaption class="figure-caption-small">🖼️ Figura 4.7: Resultat d'una segona petició al servidor amb sessions</figcaption></figure></div>

El treball amb sessions té tres parts:

- Creació o obertura de la sessió:
   Quan alguna pàgina crea una sessió utilitzant la capçalera `session_start();`(*recorda que les capçaleres han d'anar just després de `<?php`*), el servidor associa al navegador de l'usuari un identificador d'usuari únic. L'identificador es guarda en l'usuari en forma de cookie o, si el navegador de l'usuari no permet la creació de cookies, afegint l'identificador en l'adreça de la pàgina.

- Utilització de la sessió:
   Si ja s'ha creat la sessió, les pàgines sol·licitades pel mateix navegador poden guardar i recuperar informació en el servidor, informació que s'associa a l'identificador d'usuari, per la qual cosa no és accessible a altres usuaris. La informació es conserva fins que l'usuari o el servidor destruïxen la sessió.

- Destrucció o tancament de la sessió:
   Tant l'usuari com el servidor poden tancar la sessió. L'usuari pot destruir la sessió tancant el navegador. El servidor pot destruir la sessió quan alguna pàgina utilitze la funció `session_destroy();` o al cap d'un temps determinat (definit mitjançant la funció [**session_set_cookie_params()**](https://www.php.net/manual/en/function.session-set-cookie-params.php){:target="_blank"}).

Les operacions que podem fer amb la sessió són:

```php
<?php
    session_start(); // carga la sesión
    
    session_id() // devuelve el id
    $_SESSION[clave] = valor; // inserción
    
    session_destroy(); // destruye la sesión
    unset($_SESSION[clave]); // borrado
```

???examplephp "Utilització de la sessió"
    Vegem amb un exemple com podem inserir dades en la *sessió* en una pàgina per a accedir després a eixes dades en una altra pàgina. 
    === "`sesion1.php`"
        ```php
        <?php
            session_start(); // inicializamos

            $_SESSION["ies"] = "IES Mestre Ramon Esteve"; // asignación
    
            $instituto = $_SESSION["ies"]; // recuperación
            echo "Estamos en el $instituto";
        ?>
        <br />
        <a href="sesion2.php">Y luego</a>
        ```
    === "`sesion2.php`"
        ```php
        <?php
            session_start();
            $instituto = $_SESSION["ies"]; // recuperación
            echo "Otra vez, en el $instituto";
        ?>
        ```

> **Configurar la sessió en `php.ini`**
> 
> Les propietats següents de `php.ini` permeten configurar alguns aspectes de la sessió:
> 
> - `session.save_handler`: controlador que gestiona com s'emmagatzema (valor `files`).
> - `session.save_path`: ruta on s'emmagatzemen els fitxers amb les dades (si tenim un clúster, podríem usar */mnt/sessions* en tots els servidors de manera que apunten a una carpeta compartida).
> - `session.name`: nom de la sessió (PHSESSID).
> - `session.auto_start`: Es pot fer que es carregue automàticament amb cada script. Per defecte està deshabilitat.
> - `session.cookie_lifetime`: temps de vida per defecte.
> Més informació en la [**documentació oficial**](https://www.php.net/manual/es/session.configuration.php){:target="_blank"}.

> **Cookie VS session**
> 
> Les *sessions* no s'han de confondre amb les *cookies*. Les *cookies* són un mètode que permet guardar informació en l'ordinador del client per a recuperar-la en el futur, mentre que en les *sessions* la informació es manté en el servidor fins que es tanca la sessió (per intervenció de l'usuari o per temps). En el manual de PHP s'oferix un [**capítol dedicat a les sessions**](https://www.php.net/manual/en/book.session.php){:target="_blank"}.


???examplephp "Exemple"
	Heus ací un exemple gràfic d'utilització de sessions. Programa de dues pàgines que mostra gràficament els vots recollits per dues opcions.

    - La primera pàgina conté un formulari amb tres botons de tipus `submit` amb el mateix atribut `name`.<br/>
    - Dos botons permeten votar una o l'altra opció.<br/>
    - El tercer botó posa a zero els comptadors de vots.<br/>
    - La segona pàgina rep la dada, modifica la variable de sessió que conté el nombre de vots de l'opció triada (o de totes dues) i redirigix a la primera pàgina.<br/>
    - Els dos números es guarden en dues variables de sessió. Si les variables de sessió no estan definides, se'ls donarà el valor 0.<br/>
	- Les franges corresponents als vots s'allarguen de 10px en 10px i no tenen límit de grandària.
	=== "`ps1.php`"
        ```php
        <?php
        // Accedemos a la sesión
        session_name("sesion1");
        session_start();
		
        // Si algún contador no está guardado en la sesión, ponemos ambos a cero
        if (!isset($_SESSION["a"]) || !isset($_SESSION["b"])) {
            $_SESSION["a"] = $_SESSION["b"] = 0;
        }
        ?>
    	
        <!-- ... -->
        <body>
        <h2>Votar una opción</h2>
        <form action="ps2.php" method="get">
          <table>
          <tr>
            <td style="vertical-align: top;">
              <button type="submit" name="accion" value="a" 
                      style="font-size: 60px; line-height: 50px; color: hwb(200 0% 0%);">  &#x2714; </button>
            </td>
            <td>
              <?php
              // Dibujamos la primera barra
              print " <svg width=\"$_SESSION[a]\" height=\"50\">\n";
              print "   <line x1=\"0\" y1=\"25\" x2=\"$_SESSION[a]\" y2=\"25\" stroke=\"hwb(200 0% 0%)\" stroke-width=\"50\" />\n";
              print " </svg>\n";
              ?>
            </td>
          </tr>
          <tr>
            <td>
              <button type="submit" name="accion" value="b" style="font-size: 60px; line-height: 50px; color: hwb(35 0% 0%)">&#x2714;
              </button>
            </td>
              <?php
              // Dibujamos la segunda barra
              print " <td>\n";
              print " <svg width=\"$_SESSION[b]\" height=\"50\">\n";
              print "   <line x1=\"0\" y1=\"25\" x2=\"$_SESSION[b]\" y2=\"25\" stroke=\"hwb(35 0% 0%)\" stroke-width=\"50\" />\n";
              print " </svg>\n";
              print " </td>\n";
              ?>
          </tr>
          </table>
          <p>
            <button type="submit" name="accion" value="cero">Poner a cero</button>
          </p>
        </form>
        </body>
        </html>
        ```
    === "`ps2.php`"
        ```php
        <?php
        session_name("sesion1");
        session_start();
    	
        // Si alguno de los números de votos no está guardado en la sesión, redirigimos a la primera página
        if (!isset($_SESSION["a"]) || !isset($_SESSION["b"])) {
            header("Location:ps1.php");
            exit;
        }
    	
        $accion = $_GET['accion'];
        // Dependiendo de la acción recibida, modificamos el número correspondiente
        if ($accion == "a") {
            $_SESSION["a"] += 10;
        } elseif ($accion == "b") {
            $_SESSION["b"] += 10;
        } elseif ($accion == "cero") {
            $_SESSION["a"] = $_SESSION["b"] = 0;
        }
    	
        // Volvemos al formulario
        header("Location:ps1.php");
        ```
