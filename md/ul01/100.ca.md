## Continguts de la sessió 1

1. **Introducció a Laravel** Descobrix què és Laravel, la seua filosofia com a framework "opinat" i l'ecosistema complet que l'envolta. Aprendràs sobre Artisan (CLI), Tinker (REPL interactiu) i el Service Container com a cervell organitzador de Laravel.
2. **Arquitectura Client-Servidor** Comprén com es comuniquen les aplicacions web modernes. Exploraràs el model client-servidor, els ports de comunicació, el protocol HTTP/HTTPS, els mètodes HTTP (GET, POST, PUT, DELETE) i el concepte de stateless.
3. **La llar de Laravel** Coneix on viu i s'executa la teua aplicació: servidors web (Nginx/Apache) com a "porters" de l'aplicació, i tipus d'allotjament (Compartit, VPS, Dedicat, IaaS/Núvol) per a allotjar aplicacions Laravel.
4. **Eines del desenvolupador** Configura el teu entorn de desenvolupament professional amb les eines essencials: CLI/Terminal (WSL2 en Windows), editors de codi (VS Code/PHPStorm), gestors de dependències (Composer i npm), control de versions (Git), gestors de versions (NVM), entorns amb Docker i Laravel Sail, i eines de qualitat de codi (PHPStan, PHP\_CodeSniffer, Laravel Pint) i depuració (Laravel Telescope).
5. **Introducció al Frontend amb Vite i Tailwind** Aprén a integrar eines modernes de frontend amb Laravel: Vite com a compilador ultraràpid (modes desenvolupament i producció), i Tailwind CSS com a framework "utility-first" amb procés de purge per a CSS ultraoptimitzat.
6. **Anatomia de Laravel** Explora l'estructura de directoris essencial (app/, routes/, resources/, database/, public/), fitxers clau (.env, index.php), el patró MVC (Model-Vista-Controlador).


## Objectius de la sessió 1

* **Objectiu 1**: Comprendre què és Laravel com a framework "opinat" de PHP, la seua filosofia de desenvolupament, identificant-ne els avantatges i els components de l'ecosistema (Artisan, Tinker, Service Container).
* **Objectiu 2**: Entendre l'arquitectura client-servidor, els ports de comunicació, el protocol HTTP/HTTPS, els mètodes HTTP (CRUD), el concepte stateless i com Laravel processa peticions web.
* **Objectiu 3**: Identificar on s'executen les aplicacions Laravel: servidors web (Nginx/Apache) i tipus d'allotjament (Compartit, VPS, Dedicat, IaaS/Núvol).
* **Objectiu 4**: Configurar un entorn de desenvolupament professional amb CLI/Terminal, editors (VS Code/PHPStorm), gestors de dependències (Composer/npm), control de versions (Git), Docker amb Laravel Sail i eines de qualitat de codi (PHPStan, PHP\_CodeSniffer, Laravel Pint, Telescope).
* **Objectiu 5**: Conéixer les eines modernes de frontend: Vite com a compilador ultraràpid (desenvolupament vs producció) i Tailwind CSS com a framework utility-first amb procés de purge.
* **Objectiu 6**: Explorar l'estructura de directoris de Laravel, fitxers clau (.env, public/), el patró MVC i el flux complet de petició-resposta.
